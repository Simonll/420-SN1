La boucle for

Contrairement à la boucle while qui répète une action tant qu'une condition est vraie, la boucle for est conçue pour répéter des instructions un nombre connu de fois ou pour parcourir une séquence d'éléments.

---\

La fonction range()

La fonction native range() génère une séquence de nombres entiers. Elle est très souvent utilisée avec la boucle for.

# Affiche les nombres de 0 à 4 (5 itérations au total)
for i in range(5):
    print("Itération :", i)
  • range(fin) : De 0 à fin - 1.
  • range(debut, fin) : De debut à fin - 1.
  • range(debut, fin, pas) : De debut à fin - 1 avec un saut de pas.
# Affiche les nombres pairs de 2 à 10 inclusivement
for n in range(2, 11, 2):
    print(n)  # Affiche 2, 4, 6, 8, 10

Définition d'une liste

Une liste est une structure de données séquentielle capable de stocker plusieurs valeurs ordonnées dans une seule variable.

# Une liste de nombres de concentrations mesurées en laboratoire
concentrations = [100.0, 85.5, 72.8, 61.2, 50.0]
  • On utilise les crochets [] pour définir une liste.
  • Les éléments sont séparés par des virgules.

---\

Accès aux éléments par index

En Python, le premier élément d'une liste est à l'index 0.

mesures = [12.5, 14.2, 15.0]
print(mesures[0])  # Affiche 12.5 (premier élément)
print(mesures[1])  # Affiche 14.2 (deuxième élément)
print(len(mesures)) # len() retourne le nombre d'éléments (ici 3)

Parcours d'une liste avec for

Il existe deux façons de parcourir une liste avec une boucle for :

  • 1. Parcours direct par élément
  • 2. Parcours par index (avec range)
temperatures = [21.5, 22.0, 20.8, 23.1]

for temp in temperatures:
    print(f"Mesure enregistrée : {temp} °C")
temperatures = [21.5, 22.0, 20.8, 23.1]

for i in range(len(temperatures)):
    print(f"Heure {i} : {temperatures[i]} °C")

Analyse de données scientifiques

L'un des usages les plus fréquents des listes et des boucles en sciences est de calculer des métriques statistiques sur un ensemble de mesures.

Calcul du maximum, du minimum et de la moyenne
donnees = [45.2, 88.0, 92.5, 60.1, 78.4]

# 1. Calcul du maximum
max_val = donnees[0]
for val in donnees:
    if val > max_val:
        max_val = val

# 2. Calcul de la moyenne
somme = 0
for val in donnees:
    somme += val
moyenne = somme / len(donnees)

print(f"Valeur maximale : {max_val}")
print(f"Moyenne : {moyenne:.2f}")

Éviter la répétition : les boucles et les listes

En programmation, il existe une règle d'or appelée DRY (Don't Repeat Yourself - Ne vous répétez pas).

Si vous remarquez que vous êtes en train de copier-coller un bloc de code en ne changeant que quelques petites valeurs à l'intérieur, c'est le signal d'alarme : vous avez besoin d'une boucle !

Le code redondant

Voici un programme qui affiche le bulletin de trois étudiants. Remarquez comment le bloc d'instructions est répété trois fois. Seules les valeurs changent :

print("Étudiant #1")
print("Nom : Félix")
print("Note : 72")
print()

print("Étudiant #2")
print("Nom : Dayron")
print("Note : 91")
print()

print("Étudiant #3")
print("Nom : Léa")
print("Note : 58")
print()

Ce code fonctionne, mais c'est un cauchemar à maintenir. Si vous voulez ajouter un 4e étudiant, vous devez copier-coller un nouveau bloc. Pire encore : si vous décidez de changer le mot "Nom :" pour "Prénom :", vous devrez faire la modification à trois endroits différents !

Étape 1 : Extraire ce qui change

Pour corriger cela, observez les trois blocs et isolez uniquement ce qui varie :

  1. Le numéro de l'étudiant (1, 2, 3)
  2. Le nom (Félix, Dayron, Léa)
  3. La note (72, 91, 58)

Le numéro correspond en fait à la position de l'étudiant (l'index 0, 1, 2), auquel on ajoute simplement 1 pour l'affichage humain. Quant aux noms et aux notes, on va les extraire du code pour les ranger dans des listes parallèles :

noms  = ["Félix", "Dayron", "Léa"]
notes = [72, 91, 58]

✅ Étape 2 : La magie de la boucle

Maintenant que nos données sont proprement rangées dans des listes, on écrit le bloc d'affichage une seule fois et on laisse la boucle faire le travail répétitif :

noms  = ["Félix", "Dayron", "Léa"]
notes = [72, 91, 58]

nb_elements = len(noms)
for i in range(nb_elements):
    print(f"Étudiant #{i + 1}")    # On ajoute 1 à l'index pour afficher 1, 2, 3...
    print(f"Nom : {noms[i]}")      # On pige dans la liste des noms
    print(f"Note : {notes[i]}")    # On pige dans la liste des notes
    print()

Le résultat à l'écran est strictement identique à la version redondante, mais le code est devenu intelligent !

L'avantage absolu : La flexibilité

Regardez ce qui se passe si l'on veut ajouter un 4e étudiant (Tristan). On ajoute simplement ses données dans les listes, et c'est tout. La fonction len() détectera automatiquement qu'il y a maintenant 4 éléments, et la boucle s'ajustera toute seule :

noms  = ["Félix", "Dayron", "Léa", "Tristan"]
notes = [72, 91, 58, 83]

nb_elements = len(noms)
for i in range(nb_elements):
    print(f"Étudiant #{i + 1}")
    print(f"Nom : {noms[i]}")
    print(f"Note : {notes[i]}")
    print()

Le corps de la boucle (les lignes 6 à 9) n'a pas changé d'un seul caractère. C'est la véritable puissance de combiner les listes et les boucles : on sépare les données de la logique d'affichage !

Une boucle dans une boucle : l'imbrication

Il est tout à fait possible de placer une boucle à l'intérieur d'une autre boucle. On appelle cela des boucles imbriquées.
C'est la technique incontournable pour traiter des grilles en 2D, comme des pixels sur un écran, un échiquier, ou un tableau Excel (lignes et colonnes).

Voici un exemple simple avec deux boucles for imbriquées pour afficher une table de multiplication :

for i in range(1, 6):           # Boucle extérieure (gère les lignes)
    for j in range(1, 6):       # Boucle intérieure (gère les colonnes)
        print(i * j, end='\t')  # Affiche le produit avec une tabulation ('\t')
    print()                     # Change de ligne quand la ligne actuelle est finie

L'analogie de l'horloge : Pensez aux aiguilles d'une montre. La boucle intérieure (j, les minutes) doit faire un tour complet (de 1 à 5) pour que la boucle extérieure (i, les heures) avance d'un seul cran.

Exécutez ce code en débogage (point d'arrêt ligne 1) pour bien voir j tourner à toute vitesse pendant que i avance d'un pas lent.

Une grille dynamique avec while

Dans l'exemple précédent, la grille était carrée. Mais la limite de la boucle intérieure peut très bien dépendre de l'état de la boucle extérieure !

Voici un exemple générant un triangle d'étoiles :

lignes = 5
i = 1

while i <= lignes:           # Boucle extérieure (les lignes)
    j = 1
    while j <= i:            # La limite de j grandit à chaque nouvelle ligne i !
        print('*', end=' ')  # Affiche une étoile sans sauter de ligne
        j += 1
    print()                  # Saute à la ligne suivante
    i += 1

Remarquez la condition de la ligne 6 : while j <= i. À la ligne 1, la boucle interne affiche 1 étoile et s'arrête. À la ligne 5, elle doit en afficher 5 avant de s'arrêter.

Construire ses lignes d'un coup (Exercice)

Voici une fonction qui affiche un rectangle de # selon des dimensions données en paramètres :

def afficher_rectangle(largeur, hauteur):
    for i in range(hauteur):          # Répète pour chaque ligne
        for j in range(largeur):      # Répète pour chaque colonne
            print('#', end='')        # Affiche un '#' collé au précédent
        print()                       # Saute à la ligne
        
afficher_rectangle(5, 3)

(Affichera un bloc de 3 lignes par 5 colonnes)

Toutefois, appeler la fonction print() pour chaque petit caractère individuellement demande beaucoup d'efforts à l'ordinateur. Une meilleure approche consiste à construire la ligne complète en mémoire à l'aide de la concaténation, puis à l'afficher en une seule fois :

def afficher_rectangle(largeur, hauteur):
    for _ in range(hauteur):          # Le numéro du tour n'est pas utilisé (_)
        ligne = ''                    # Initialise une boîte vide (chaîne) pour la ligne
        for j in range(largeur):
            ligne += '#'              # Ajoute les '#' un par un dans la boîte
        print(ligne)                  # Affiche la boîte complète d'un seul coup
        
afficher_rectangle(5, 3)

Testez-le en débogage : Observez la variable ligne s'allonger petit à petit (#, puis ##, puis ###) à chaque tour de la boucle intérieure.

Le "super-pouvoir" Pythonique : multiplier du texte !

Dans de nombreux langages de programmation, la boucle imbriquée que nous venons de voir est la seule façon de construire cette ligne.

Mais Python possède une astuce incroyablement performante : la multiplication de chaînes de caractères. Vous pouvez éviter complètement la boucle intérieure en multipliant simplement votre caractère :

def afficher_rectangle_pro(largeur, hauteur):
    for _ in range(hauteur):
        # Crée une ligne de X caractères instantanément !
        print('#' * largeur)

C'est la méthode la plus rapide et la plus élégante en Python pour répéter un motif.
Mais vous pouriez aussi utiliser la fonction join :

def afficher_rectangle_pro(largeur, hauteur):
    for _ in range(hauteur):
    # Crée une ligne de X caractères instantanément !
    print("".join(["#" for _ in range(largeur)]))

Notions visées

Boucle for, parcours d'une liste, variables accumulatrices (compteur, somme), recherche de min/max sans fonction prédéfinie, initialisation au premier élément, calcul de moyenne post-boucle, efficacité algorithmique (un seul parcours au lieu de deux).

Exercice - Énumérer des décimales (Précision de l'ordinateur)

Créez un fichier decimales.py pour votre réponse.

À la Rencontre #2, vous avez découvert que les nombres à virgule flottante ne sont pas toujours exacts en informatique (0.1 + 0.2 donne 0.30000000000000004). On va maintenant utiliser une boucle imbriquée pour observer ce phénomène à plus grande échelle.

Bob veut énumérer les décimales de 0.1 à 0.9, puis de 0.01 à 0.09, puis de 0.001 à 0.009. Il les calcule en multipliant un chiffre i (allant de 1 à 9) par une puissance négative de 10 :

for puissance in range(1, 4):       # puissance vaut 1, puis 2, puis 3
    for i in range(1, 10):          # i vaut 1, 2, ..., 9
        nombre = i * 10 ** -puissance
        print(nombre, end="  ")
    print()                         # Saut de ligne après chaque groupe de 9

PARTIE 1 - Observer​

Exécutez ce code et observez la sortie. Repérez visuellement les nombres qui ne s'affichent pas exactement comme prévu (par exemple, 0.30000000000000004 au lieu de 0.3).

PARTIE 2 - Comparer avec round()​

Modifiez la boucle intérieure pour afficher, à côté de chaque nombre, sa version proprement arrondie avec round(nombre, puissance). Pour chaque valeur, utilisez une condition (if) pour afficher si les deux valeurs sont "identiques" ou si elles sont "DIFFÉRENTES".

✅ Exemple de sortie attendue (extrait) :

0.1 → round: 0.1 → identique
0.2 → round: 0.2 → identique
0.30000000000000004 → round: 0.3 → DIFFÉRENT
0.4 → round: 0.4 → identique

Pour aller plus loin​

  1. Augmentez la portée du programme pour générer des décimales jusqu'à 0.000000001 en changeant une seule valeur dans votre code.
  2. Bob a essayé une autre méthode pour générer les mêmes décimales : au lieu d'utiliser une multiplication, il construit le texte de la décimale, puis le convertit en nombre réel (float). Remplacez la ligne de calcul (nombre = i * 10 ** -puissance) par celle-ci :
nombre = float("0." + "0" * (puissance - 1) + str(i))

Exécutez à nouveau votre programme de la Partie 2 avec cette nouvelle méthode. Que remarquez-vous ? Y a-t-il encore des nombres marqués « DIFFÉRENT » ?

La morale de l'histoire : Cette expérience illustre une notion fondamentale en programmation : le niveau de précision dépend souvent de la façon dont on calcule la valeur, et pas seulement de la valeur elle-même !

Notions visées

Boucles imbriquées (for), range(), opérateur de puissance (**), précision des flottants, round(), structure conditionnelle, paramètre end dans print(), conversion str → float.

Exercice - Refactorisation : Le générateur de nombres

Créez un fichier generer_nombre.py pour votre réponse.

Le code ci-dessous permet de générer un nombre de 3 chiffres (sans aucun zéro à l'intérieur), mais il souffre d'un sérieux problème de répétition :

import random

def generer_nombre():
    nombre = 0

    position = 0
    chiffre_aleatoire = random.randint(1, 9)
    nombre += chiffre_aleatoire * 10 ** position   # 10**0 = 1

    position = 1
    chiffre_aleatoire = random.randint(1, 9)
    nombre += chiffre_aleatoire * 10 ** position   # 10**1 = 10

    position = 2
    chiffre_aleatoire = random.randint(1, 9)
    nombre += chiffre_aleatoire * 10 ** position   # 10**2 = 100

    return nombre

resultat = generer_nombre()
print(f"Nombre généré : {resultat}")

VOTRE MISSION​

  • Modifiez le code de cette fonction en utilisant une boucle pour éliminer complètement la répétition (application du fameux principe DRY - Don't Repeat Yourself).
  • Ajoutez un paramètre optionnel à la fonction pour permettre de choisir la longueur du nombre à générer. La valeur par défaut de ce paramètre doit rester 3.
Notions visées

Boucles (for/while), refactorisation (DRY), définition de fonction, paramètre avec valeur par défaut, module random, opérateurs arithmétiques (puissances de 10).

ÉTAPES À SUIVRE​

  1. COMPRENDRE LE MOTIF Exécutez le code dans votre éditeur et observez le motif affiché. Chaque ligne contient un nombre croissant d’étoiles, allant de 1 à 4.
  2. IDENTIFIER LA RÉPÉTITION Observez la structure pour tenter de la généraliser. Pour chaque ligne, vous remarquerez que l'on fait toujours les deux mêmes actions :

Boucles imbriquées (for), paramètre end de la fonction print, identification de répétitions, généralisation d'un motif.
