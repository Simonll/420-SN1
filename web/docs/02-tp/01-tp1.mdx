<TabItem value="partie1" label="Partie 1 : Fonctions de calcul (R1-R3)" default>

Dans le fichier `cinetique.py`, implémentez les fonctions suivantes :

1. **`calculer_concentration(c0, k, temps)`** :
   Calcul de la concentration restante selon la formule de décomposition de premier ordre :
   $$C(t) = C_0 \cdot e^{-k \cdot t}$$
   *(Utilisez `math.exp()` du module `math`.)*
   
   :::danger Validation obligatoire (R4+)
   À partir de **R4**, vous devez **valider les paramètres** avec `raise ValueError()` :
   - `c0` doit être ≥ 0 (concentration non-négative)
   - `k` doit être > 0 (constante positive)
   - `temps` doit être ≥ 0 (temps non-négatif)
   
   **Exemple :**
   ```python
   def calculer_concentration(c0, k, temps):
       if c0 < 0:
           raise ValueError("c0 (concentration initiale) doit être non-négative")
       if k <= 0:
           raise ValueError("k (constante de vitesse) doit être strictement positive")
       if temps < 0:
           raise ValueError("temps doit être non-négatif")
       return c0 * math.exp(-k * temps)
   ```
   :::

:::info Bien comprendre la formule C(t) = C₀ · e^(−k·t)
Cette formule modélise une **décomposition de premier ordre** : la quantité d'une substance diminue de façon proportionnelle à la quantité encore présente, à chaque instant. C'est le modèle qui décrit, entre autres, l'élimination d'un médicament dans le sang ou la décomposition d'un réactif chimique.

- **C(t)** — la concentration restante à l'instant `t` (le résultat retourné).
- **C₀** — la concentration initiale, au temps `t = 0` (point de départ, toujours la valeur maximale).
- **e** — la constante d'Euler (≈ 2,718), la base des logarithmes naturels. Son rôle est de décrire une décroissance « exponentielle ».
- **k** — la constante de vitesse de décomposition (positive, en unités d'inverse du temps). Plus `k` est grand, plus la substance disparaît vite.
- **t** — le temps écoulé.
- **e^(−k·t)** — le facteur de décroissance : il vaut 1 à `t = 0` (donc C(0) = C₀), puis tend vers 0 sans jamais l'atteindre.

**Propriétés importantes :**

- La concentration **décroît de façon exponentielle** : elle chute rapidement au début, puis de plus en plus lentement.
- La courbe **ne touche jamais zéro** — décroissance asymptotique.
- Le temps de demi-vie t₁/₂ = ln(2)/k est constant : la substance met **toujours le même temps** pour perdre la moitié de sa concentration, quelle que soit la quantité de départ.
- Un `k` plus grand = décroissance plus rapide ; un `k` plus petit = décroissance plus lente.
:::

2. **`calculer_demi_vie(k)`** :
   Calcule le temps de demi-vie ($t_{1/2}$) nécessaire pour que la concentration soit divisée par 2 :
   $$t_{1/2} = \frac{\ln(2)}{k}$$
   
   :::info Validation (R4+)
   Validez que `k` > 0 (sinon lever `ValueError`).
   :::

3. **`convertir_concentration(valeur, unite_source, unite_cible)`** :
   Convertit une concentration entre deux unités courantes en pharmacopée :
   - `"mg/L"` ↔ `"µg/mL"` (facteur de conversion : 1 mg/L = 1 µg/mL pusique 1 L = 1000 mL et 1 mg = 1000 µg)
   
   :::info Conversions d'unités en pharmacologie
   Les concentrations plasmatiques se mesurent en différentes unités selon le contexte :
   - **mg/L** (milligrammes par litre) : standard pour les suivi sanguin courant
   - **µg/mL** (microgrammes par millilitre) : pour les substances très puissantes
   
   La conversion est simple : 1 mg/L = 1 µg/mL
   :::

<TabItem value="partie2" label="Partie 2 : Analyse des seuils (R4)">

Dans le fichier `cinetique.py`, ajoutez la fonction d'évaluation des seuils :

4. **`evaluer_niveau(concentration, seuil_min, seuil_max)`** :
   Retourne un message sous forme de chaîne de caractères (`str`) selon le niveau :
   - `"INSUFFISANT"` si $C < \text{seuil\_min}$
   - `"OPTIMAL"` si $\text{seuil\_min} \le C \le \text{seuil\_max}$
   - `"TOXIQUE / CRITIQUE"` si $C > \text{seuil\_max}$

:::warning Attention aux cas limites
Testez votre fonction avec les **valeurs exactes** des seuils :
- Si concentration = 20 et seuil_min = 20, le résultat doit être `"OPTIMAL"` (pas `"INSUFFISANT"`)
- Si concentration = 80 et seuil_max = 80, le résultat doit être `"OPTIMAL"` (pas `"TOXIQUE"`)

**Exemples de test :**
```python
evaluer_niveau(15, 20, 80)  # → "INSUFFISANT"
evaluer_niveau(20, 20, 80)  # → "OPTIMAL"
evaluer_niveau(50, 20, 80)  # → "OPTIMAL"
evaluer_niveau(80, 20, 80)  # → "OPTIMAL"
evaluer_niveau(85, 20, 80)  # → "TOXIQUE / CRITIQUE"
```
:::

:::info Validation (R4+)
Validez avec `raise ValueError()` que :
- `concentration`, `seuil_min`, `seuil_max` sont tous des nombres (float ou int)
- `seuil_min` < `seuil_max` (sinon les seuils n'ont pas de sens)

**Exemple de validation :**
```python
if seuil_min >= seuil_max:
    raise ValueError("seuil_min doit être < seuil_max")
```
:::

Dans le fichier `analyse.py` :

4. **`simuler_evolution(c0, k, duree_heures)`** :
   Génère et retourne une **liste** contenant la concentration calculée pour chaque heure de $t = 0$ jusqu'à $t = \text{duree\_heures}$.
   
   :::info Fonction de simulation
   Cette fonction doit appeler `calculer_concentration()` de `cinetique.py` pour chaque heure et accumuler les résultats dans une liste.
   Utilisez une boucle `for` avec `range()` ou une boucle `while` pour itérer heure par heure.
   :::

   :::info Validation (R5+)
   Validez avec `raise ValueError()` que :
   - `c0` > 0 (concentration initiale positive)
   - `k` > 0 (constante positive)
   - `duree_heures` > 0 (durée positive)
   :::

5. **`analyser_resultats(liste_concentrations, seuil_min, seuil_max)`** :
   Analyse la liste des concentrations et retourne un **rapport simple** (chaîne de caractères) contenant :
   - La concentration maximale ($C_{max}$).
   - Le nombre d'heures pendant lesquelles la concentration est restée dans la zone `"OPTIMAL"`.

   :::info Validation (R6+)
   Validez avec `raise ValueError()` que :
   - `liste_concentrations` est une liste non-vide
   - `seuil_min` < `seuil_max` (sinon les seuils n'ont pas de sens)
   - Tous les éléments de la liste sont des nombres
   :::
