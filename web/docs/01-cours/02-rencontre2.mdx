                ::::info Exercice - MOYENNE PRESSION SYSTOLIQUE
                Créez un fichier `pression_systolique.py` pour votre réponse.

                Créez un programme calculant la moyenne de la pression systolique d'un patient.

                #### **INSTRUCTIONS**

                1. **Déclarez une liste** `mesures` contenant les 3 valeurs de pression systolique (matin, midi, soir) :
                    ```python
                    mesures = [125, 130, 180]
                    ```
                2. **Affichez chaque mesure** en accédant aux éléments de la liste par leur index (`mesures[0]`, `mesures[1]`, `mesures[2]`).
                3. **Calculez la moyenne** à l'aide des fonctions `sum()` et `len()` appliquées directement sur la liste.
                4. **Affichez le résultat** de façon claire et lisible.

                Validez le bon fonctionnement de votre programme en modifiant les valeurs dans la liste.

                :::tip Pourquoi une liste?
                Les trois mesures sont des données **du même type** (des pressions) collectées de façon répétée. Une liste les regroupe naturellement. De plus, utiliser `sum()` et `len()` rend votre calcul **généralisant** : il fonctionnerait sans modification avec 4, 5 ou 10 mesures dans la liste.
                :::
                <br/>

                Sortie attendue
                ```
                Pression systolique

                Mesure du matin : 125
                Mesure du midi : 130
                Mesure du soir : 180

                Moyenne de la pression systolique : 145.0 mmHg
                ```

                :::note Notions visées
                Listes, accès par index, `sum()`, `len()`
                :::

                ::::info Exercice - CALCUL DE LA DISTANCE ENTRE 2 POINTS
                Créez un fichier `distance_2_points.py` pour votre réponse.

                Créez un programme **calculant et affichant** la distance entre les 2 points, arrondie à 2 décimales.<br />
                La formule de la distance entre 2 points $A(x_1, y_1)$ et $B(x_2, y_2)$ est :

                $$
                d = \sqrt{(x_2 - x_1) ^ 2 + (y_2 - y_1) ^ 2}
                $$

                Représentez les deux points dans **une seule liste `points`** contenant deux sous-listes :
                ```python
                points = [
                    [50, 70],   # point A : [x1, y1]
                    [80, 60],   # point B : [x2, y2]
                ]
                ```
                Accédez aux coordonnées via les index : `points[1][0]` pour $x_2$. \
                Pour réaliser la racine carrée de la formule, vous aurez besoin d'une fonction du module `math`.

                :::tip Pourquoi une liste de listes?
                Chaque point est lui-même une liste `[x, y]`, et `points` regroupe tous les points du problème. Cette structure, appelée **liste de listes** (ou liste imbriquée), reflète naturellement la réalité : un ensemble de points, chacun défini par ses coordonnées. `points[0]` est le point A, `points[1]` est le point B.
                :::

                Sortie attendue
                ```
                Point A
                X1 : 50
                Y1 : 70

                Point B
                X2 : 80
                Y2 : 60

                Distance : 31.62
                ```

                :::note Notions visées
                Listes imbriquées (liste de listes), accès par double index, module `math` (racine carrée), opérateurs arithmétiques (`**`), `round()`
                :::

                ::::info Exercice - CALCUL DE LA NOTE FINALE DU COURS
                Créez un fichier `note_finale.py` pour votre réponse.


                Créez un programme qui calcule la note finale obtenue par un étudiant dans ce cours. \
                La règle de la double sanction n'est pas à appliquer dans cet exercice, car les notions nécessaires n'ont pas encore été vues.

                #### **INSTRUCTIONS**
                1. **Déclarez une variable** pour le nom de l'étudiant et **quatre listes parallèles** :
                    ```python
                    nom_etudiant = "Nicola Tesla"
                    evaluations  = ["TP1",  "TP2",  "Examen 1", "Examen 2"]
                    notes        = [16,      21,      90,         95]
                    sur          = [20,     25,     100,        100]
                    ponderations = [0.20,   0.25,   0.20,       0.35]
                    ```
                2. **Appliquez les pondérations** pour calculer la note finale en accédant aux éléments par leur index.
                3. **Affichez un résumé clair** des notes de chaque évaluation et de la note finale, arrondies à 2 décimales.

                :::tip Pourquoi des listes?
                Ces quatre listes sont **parallèles** : à l'index `0`, on trouve tout ce qui concerne le TP1 (`evaluations[0]`, `notes[0]`, `sur[0]`, `ponderations[0]`). Regrouper les données de cette façon évite de multiplier les variables et prépare le terrain pour les boucles `for` que vous verrez bientôt.
                :::

                Vous pouvez créer d'autres variables si vous le jugez nécessaire.

                Sortie attendue
                ```
                Étudiant : Nicola Tesla
                TP1        (20%) :  16 / 20
                TP2        (25%) :  21 / 25
                Examen 1   (20%) : 90 / 100
                Examen 2   (35%) : 95 / 100
                Note obtenue pour ce cours : 88.25 / 100
                Attention, l'application de la double sanction n'a pas été réalisée!
                ```

                :::note Notions visées
                Listes parallèles, accès par index, opérateurs arithmétiques, `round()`, f-strings

                ::::info Exercice - DÉCOMPOSER UN MONTANT EN BILLETS
                Créez un fichier `montant_billets.py` pour votre réponse.

                Écrivez un programme permettant de décomposer un montant en billets de 100, 50, 20, 10 et 5\$.<br />
                Le programme doit privilégier les billets de plus grandes valeurs.

                Voici un exemple d'exécution :

                ```
                Montant : 376.54
                Billets :
                3 x 100$
                1 x 50$
                1 x 20$
                0 x 10$
                1 x 5$
                Reste 1.54$
                ```

                Indices :
                - Le début de votre programme est le suivant, **déclarez les coupures disponibles dans une liste** :
                    ```python
                    montant_initial = 376.54
                    billets = [100, 50, 20, 10, 5]  # coupures disponibles, du plus grand au plus petit
                    ```
                - Traitez les coupures une à la fois, en commençant par `billets[0]`.
                - Accédez à chaque valeur de coupure via son index : `billets[0]` pour 100\$, `billets[1]` pour 50\$, etc.
                - Créez autant de variables que vous le croyez nécessaire (ex : montant_restant, nb_billets_requis, etc.)
                - Vous aurez besoin de l'opérateur pour la division entière (`//`), par exemple :
                    - `376 // 100` $\longrightarrow$ `3`
                    - `95 // 100` $\longrightarrow$ `0`

                :::tip Pourquoi une liste?
                Les valeurs de coupures forment une série naturellement ordonnée. Les stocker dans une liste rend l'intention du code plus claire. Vous verrez lors d'un prochain cours qu'une boucle `for` permettrait de traiter automatiquement toutes les coupures, peu importe leur nombre, en quelques lignes seulement.
                :::

                :::note Notions visées
                Listes, accès par index, division entière (`//`) et modulo, opérateurs arithmétiques, variables intermédiaires
                :::

                * Déclarez une variable pour la hauteur.

                * Arrondissez le résultat à 2 décimales.
                * Affichez le résultat selon le format ci-dessous.

                **Exemple attendu (pour $h = 5$) :**
                ```
                Hauteur : 5
                La vitesse d'impact est de 9.90 m/s
                ```
