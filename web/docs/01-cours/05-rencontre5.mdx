    <TabItem value="while" label="while" default>

        :::info Introduction aux boucles
        Les boucles apportent une puissance considérable à vos programmes. Elles permettent de répéter des actions, de parcourir des listes et de traiter des données massivement sans avoir à copier-coller du code. Avec les variables et les conditions, c'est l'un des piliers de la programmation.

        Voici la logique fondamentale d'une boucle :
        ```pseudo showLineNumbers
        Tant que (cette condition est vraie) :
            # Exécuter cette instruction
            # Et celle-ci
        # Suite du programme (exécuté quand la condition devient fausse)

        ```
        Si on exécutait ce pseudo-code, on répéterait l'exécution des lignes 2 à 4 tant que la condition de la ligne 1 est vraie.\
        Dès que la condition devient fausse, on sort de la boucle et on continue l'exécution du programme à la ligne 5.

        En Python, on traduit le "Tant que" par le mot-clé `while`.
        Voici un exemple classique :
        
        ```python showLineNumbers
        compteur = 0
        while compteur < 5:
            print("Compteur =", compteur)
            compteur = compteur + 1  # Incrémente le compteur de 1
        print("Fin de la boucle")
        ```
        
        **Que se passe-t-il ici ?**

        1. Python évalue la condition : est-ce que `0 < 5` ? Oui (`True`).
        2. Il entre dans la boucle, affiche "0", et ajoute 1 à `compteur`.
        3. Il remonte à la ligne 2 pour vérifier à nouveau. Est-ce que `1 < 5` ? Oui.
        4. À chaque tour (qu'on appelle une **itération**), `compteur` augmente.
        5. Quand `compteur` atteint 5, la condition `5 < 5` devient fausse (`False`). Python saute alors par-dessus la boucle et passe à la ligne 5.

        **Le meilleur moyen de comprendre :** Exécutez ce code en mode débogage ! Mettez un point d'arrêt sur la ligne 1 et avancez une ligne à la fois pour voir la variable `compteur` grandir à chaque tour.

        :::

        ---

        :::warning Attention aux boucles infinies
        Il est crucial de s'assurer que la condition de la boucle deviendra **fausse** à un moment donné.\
        
        Si vous oubliez la ligne `compteur = compteur + 1` dans l'exemple précédent, `compteur` restera éternellement à 0. La condition `0 < 5` sera toujours vraie, ce qui créera une **boucle infinie** et fera planter ou figer votre programme.
        :::

        ---

        :::tip affectation raccourcie
        Pour incrémenter une variable, les programmeurs utilisent un raccourci très pratique : l'opérateur `+=`.
        Au lieu d'écrire le nom de la variable deux fois (`compteur = compteur + 1`), on écrit simplement `compteur += 1`.

        Cela fonctionne de la même manière pour toutes les opérations mathématiques : `-=`, `*=`, `/=`.

        Voici le même code, écrit de façon plus moderne :

        ```python showLineNumbers
        compteur = 0
        while compteur < 5:
            print("Compteur =", compteur)
            compteur += 1  # Fait exactement la même chose !
        print("Fin de la boucle")
        ```
        :::

        ---

        :::info Un exemple pratique : L'accumulateur
        Voici un autre usage classique de la boucle `while` : additionner une série de nombres (ici, de 1 à 10). Ce principe de programmation s'appelle l'**accumulateur**.

        ```python showLineNumbers
        somme = 0
        nombre = 1

        while nombre <= 10:
            somme += nombre  # Ajoute le nombre actuel au total
            nombre += 1      # Passe au prochain nombre
            
        print("La somme des nombres de 1 à 10 est :", somme)

        ```

        Dans cet exemple, nous avons deux variables qui travaillent en équipe :

        * `nombre` agit comme notre **compteur** (1, 2, 3... jusqu'à 11).
        * `somme` agit comme notre **accumulateur** (il accumule les valeurs à chaque tour : 1, puis 3, puis 6...).

        Encore une fois, exécutez-le en mode débogage pour voir les variables `somme` et `nombre` évoluer en tandem à chaque itération !
        :::

    <TabItem value="affectation" label="Affectation">

        :::info Les opérateurs d'affectation

        Nous avons déjà utilisé l'opérateur `=` classique pour affecter une valeur de départ à une variable :
        ```python
        x = 5

        ```

        Mais en programmation, il est très fréquent de devoir modifier une variable en utilisant sa propre valeur (par exemple : ajouter 1 à un compteur, ou doubler un score).

        Plutôt que d'écrire le nom de la variable deux fois (ex. : `x = x + 1`), Python propose des **opérateurs d'affectation raccourcis**. Ils effectuent l'opération mathématique et sauvegardent le résultat dans la même variable, en une seule étape.

        Voici les opérateurs d'affectation composés les plus courants :

        | Opérateur | Description                          | Exemple               | Équivalent à          |
        |-----------|--------------------------------------|-----------------------|-----------------------|
        | <C>+=</C> | Addition et affectation | <C>a += b</C> | <C>a = a + b</C> |
        | <C>-=</C> | Soustraction et affectation | <C>a -= b</C> | <C>a = a - b</C> |
        | <C>*=</C> | Multiplication et affectation | <C>a *= b</C> | <C>a = a * b</C> |
        | <C>/=</C> | Division et affectation | <C>a /= b</C> | <C>a = a / b</C> |
        | <C>%=</C> | Modulo et affectation | <C>a %= b</C> | <C>a = a % b</C> |
        | <C>//=</C> | Division entière et affectation | <C>a //= b</C> | <C>a = a // b</C> |
        | <C>**=</C> | Exponentiation et affectation | <C>a **= b</C> | <C>a = a ** b</C> |

        :::

        ---

        :::tip En pratique
        Ces raccourcis rendent votre code beaucoup plus lisible, surtout quand vos variables ont des noms descriptifs et longs !
        ```python
        compteur = 0
        compteur += 1  # équivalent à compteur = compteur + 1
        compteur *= 2  # équivalent à compteur = compteur * 2
        compteur += 8  # 2 + 8 -> compteur vaut maintenant 10
        print(compteur)  # Affiche 10
        ```
        :::

    <TabItem value="for" label="range / for">

        :::tip La fonction `range()`
        La fonction `range()` génère une séquence de nombres. Il existe 3 façons de l'appeler selon le nombre de paramètres fournis :

        - `range(stop)` : part de `0` (par défaut), avance de `1` (par défaut) et s'arrête **juste avant** `stop`.
        - `range(start, stop)` : part de `start`, avance de `1` et s'arrête avant `stop`.
        - `range(start, stop, step)` : part de `start`, avance par bonds de `step` et s'arrête avant `stop`.

        | Appel             | Produit les nombres    |
        |-------------------|------------------------|
        | <C><B>range</B>(<N>5</N>)</C> | <C><N>0</N>, <N>1</N>, <N>2</N>, <N>3</N>, <N>4</N></C> |
        | <C><B>range</B>(<N>1</N>, <N>5</N>)</C> | <C><N>1</N>, <N>2</N>, <N>3</N>, <N>4</N></C> |
        | <C><B>range</B>(<N>0</N>, <N>11</N>, <N>2</N>)</C> | <C><N>0</N>, <N>2</N>, <N>4</N>, <N>6</N>, <N>8</N>, <N>10</N></C> |
        | <C><B>range</B>(<N>5</N>, <N>0</N>, -<N>1</N>)</C> | <C><N>5</N>, <N>4</N>, <N>3</N>, <N>2</N>, <N>1</N></C> |

        *Note : `range()` n'est pas techniquement une liste en Python, mais elle se comporte exactement comme telle lorsqu'on la parcourt.*
        :::

        ---

        ::::info Boucle `for` avec `range()`
        La boucle `for` parcourt une séquence de valeurs **une par une**, et exécute son bloc d'instructions à chaque itération (à chaque tour).

        Sa structure est la suivante :
        ```python showLineNumbers
        for i in range(start, stop, step):
            # instructions répétées à chaque itération
        ```

        À chaque tour de boucle, la variable `i` prend automatiquement la valeur suivante dans la séquence produite par `range()`.

        :::tip À noter
        La boucle `for` est en réalité un cas particulier de la boucle `while`. Elle est simplement beaucoup plus pratique lorsqu'on sait d'avance combien de tours on veut effectuer.
        :::

        Voici quatre exemples pour bien comprendre la mécanique. Lisez le commentaire, puis le code :

        ```python showLineNumbers
        # Exemple 1 : i vaut 0, puis 1, 2, 3, 4 (5 tours au total)
        for i in range(5):
            print(i)

        # Exemple 2 : i commence à 1 et s'arrête juste avant 6
        for i in range(1, 6):
            print(i)

        # Exemple 3 : i avance de 2 en 2 (affiche seulement les nombres pairs)
        for i in range(0, 11, 2):
            print(i)

        # Exemple 4 : step négatif → i entame un compte à rebours de 5 jusqu'à 1
        for i in range(5, 0, -1):
            print(i)

        ```

        **Le meilleur test :** Exécutez ces exemples en mode débogage, un à la fois. Placez un point d'arrêt sur le `for` et avancez ligne par ligne pour voir la variable `i` changer de valeur sous vos yeux !
        ::::

        ---

        :::info Parcourir une liste avec `for`, `range()` et `len()`
        Puisque `range()` produit une séquence d'index (`0`, `1`, `2`…), c'est l'outil idéal pour générer les **index** permettant de lire une liste.

        Rappel : `len(liste)` retourne le nombre d'éléments d'une liste. Par conséquent, `range(len(liste))` générera exactement les bons index pour parcourir cette liste du début à la fin.

        ```python showLineNumbers
        consoles = ["PS5", "Xbox Series X", "Nintendo Switch 2"]
        nb_elements = len(consoles)       # nb_elements vaut 3
        for i in range(nb_elements):      # i prendra les valeurs 0, 1, 2
            print(consoles[i])            # accède à l'élément à la position i de la liste consoles

        # En pratique, les programmeurs l'écrivent souvent sur une seule ligne :
        # for i in range(len(consoles)):
        ```

        **Ce qui se passe en coulisses :**

        * **1er tour :** `i` vaut `0` → `consoles[0]` → `"PS5"`
        * **2e tour :** `i` vaut `1` → `consoles[1]` → `"Xbox Series X"`
        * **3e tour :** `i` vaut `2` → `consoles[2]` → `"Nintendo Switch 2"`

        Exécutez ce code en mode débogage et observez `i` et `consoles[i]` évoluer ensemble à chaque itération.
        :::

        ---

        :::tip Quand on n'utilise pas `i` : la convention `_`
        Parfois, on veut simplement **répéter une action** un certain nombre de fois, sans jamais utiliser la valeur de `i` à l'intérieur de la boucle.

        Par exemple, afficher 5 fois le même message :
        ```python showLineNumbers
        for i in range(5):
            print("Bienvenue!")  # i n'est pas utilisé
        ```

        Dans ce cas, nommer la variable `i` peut être trompeur, car cela laisse croire à un autre programmeur qu'elle servira à un calcul.
        En Python, la convention est d'utiliser le tiret bas (`_`) pour signaler explicitement que la variable de boucle est intentionnellement ignorée :

        ```python showLineNumbers {1}
        for _ in range(5):
            print("Bienvenue !")  # On répète 5 fois, le numéro du tour ne nous intéresse pas

        ```

        Le résultat est identique, mais le `_` communique clairement votre intention : *"Je n'ai pas besoin de savoir à quel tour je suis, je veux juste répéter."*

        :::

        ---

        :::warning Le grand duel : `for` ou `while`? Savoir choisir
        La règle est simple : **`for` quand on connaît le nombre de tours d'avance, `while` quand on ne le connaît pas**.

        Utilisez un **`for`** lorsque le nombre d'itérations est **connu ou calculable avant** même d'entrer dans la boucle :

        * *Afficher les 12 mois de l'année* → On sait qu'il y en a exactement 12.
        * *Parcourir une liste de 30 étudiants* → `len(liste)` nous donne le compte exact d'avance.
        * *Calculer la table de multiplication de 7 (de 1 à 10)* → Exactement 10 tours.
        * *Répéter une action 5 fois* → Le nombre est fixé d'avance.

        Utilisez un **`while`** lorsque le nombre d'itérations **dépend d'un événement qui survient pendant l'exécution** (il est donc impossible à prédire) :

        * *Redemander un mot de passe tant qu'il est incorrect* → L'utilisateur peut réussir au 1er essai... ou au 50e.
        * *Générer des nombres aléatoires jusqu'à obtenir un 6* → Cela peut prendre 1 tour comme 100 tours.
        * *Faire durer une partie de jeu vidéo tant que le joueur a des points de vie* → La durée de la partie est inconnue.

        **Le test mental ultime :** *« Est-ce que je pourrais écrire le nombre total de tours sur un bout de papier AVANT que l'ordinateur ne lance la boucle ? »*
        Si oui → `for`.
        Si non → `while`.
        :::

    <TabItem value="forif" label="Structures combinées">

        :::info Combiner les structures

        En programmation, la véritable puissance apparaît lorsqu'on assemble nos outils. Il est très courant d'imbriquer des boucles à l'intérieur d'autres boucles, ou de placer des conditions (`if/else`) à l'intérieur d'une boucle.

        Voici un exemple classique qui combine une boucle `for` avec une condition `if` pour trouver et afficher uniquement les nombres pairs entre 0 et 10 :

        ```python showLineNumbers
        for i in range(11):
            if i % 2 == 0:
                print(i)

        ```
        **Comment ça fonctionne :**
        La boucle `for` fait défiler les nombres de 0 à 10. À chaque tour, la condition `if` agit comme un filtre. Elle vérifie si le nombre actuel est pair (c'est-à-dire si le reste de sa division par 2 est égal à 0, grâce à l'opérateur modulo `%`). Si le test est vrai, le nombre est affiché ; sinon, Python passe directement au prochain tour de boucle.

        **À tester :** Exécutez ce code en mode débogage. Mettez un point d'arrêt sur la ligne 1 et avancez ligne par ligne. Vous verrez l'ordinateur "sauter" par-dessus le `print` lorsque la variable `i` contient un nombre impair !

        :::

        ---

        :::info Exemple pratique avec une liste
        Filtrer ou catégoriser des données est l'une des tâches les plus fréquentes en informatique. On combine presque toujours un `for` et un `if` pour analyser les éléments d'une liste un par un.

        Voici un programme qui parcourt une liste de températures corporelles et pose un diagnostic pour chacune d'elles :

        ```python showLineNumbers
        temperatures = [36.5, 38.2, 37.1, 39.8, 36.9]

        for i in range(len(temperatures)):
            if temperatures[i] > 37.5:
                print(f"{temperatures[i]}°C : fièvre !")
            else:
                print(f"{temperatures[i]}°C : normale")

        ```

        **La mécanique interne :**
        À chaque itération, la variable `i` (notre index) avance d'une position (0, 1, 2, 3, 4). L'expression `temperatures[i]` extrait la valeur contenue dans cette case, puis la structure `if/else` décide immédiatement de l'aiguillage à prendre (fièvre ou normale).

        **L'habitude à prendre :** Exécutez ce code en mode débogage. C'est la meilleure façon de voir concrètement comment la variable `i` (la position) et `temperatures[i]` (la donnée réelle) travaillent en équipe à chaque nouveau tour de boucle.
        :::

    <TabItem value="break" label="break / continue / pass">

        :::info Contrôler le flux `break`, `continue` et `pass`

        Normalement, une boucle s'exécute jusqu'à ce que sa condition devienne fausse ou qu'elle ait parcouru tous ses éléments. Mais parfois, on veut **prendre le contrôle** : arrêter la boucle prématurément ou sauter une étape spécifique.

        Python propose trois instructions pour gérer ces situations.

        :::

        ---

        :::info Le frein d'urgence : `break`
        L'instruction `break` permet de **sortir immédiatement** d'une boucle (`for` ou `while`), même si elle n'avait pas terminé son travail. Dès que Python lit `break`, il abandonne la boucle et passe à la suite du programme.

        *Cas d'usage typique :* On cherche un élément précis dans une base de données. Dès qu'on le trouve, on fait un `break` pour arrêter de chercher et ne pas gaspiller de puissance de calcul.

        ```python showLineNumbers
        for i in range(10):
            if i == 5:
                break  # Interrompt définitivement la boucle
            print(i)

        print("Fin de la boucle")
        # Affiche : 0, 1, 2, 3, 4, puis "Fin de la boucle"
        ```

        :::

        ---

        :::info Le saut d'obstacle : `continue`
        L'instruction `continue` ne détruit pas la boucle, mais elle **annule le tour en cours**. Dès que Python lit `continue`, il ignore toutes les instructions qui suivent et remonte immédiatement au début de la boucle pour entamer le tour suivant.

        *Cas d'usage typique :* On parcourt une liste de fichiers et on utilise `continue` pour sauter ceux qui sont corrompus ou invalides.

        ```python showLineNumbers
        for i in range(10):
            if i % 2 == 0:
                continue  # Saute par-dessus le print() si le nombre est pair
            print(i)

        # N'affichera que les nombres impairs : 1, 3, 5, 7, 9

        ```

        :::

        ---

        :::info Le bouche-trou (espace réservé) : `pass`
        L'instruction `pass` est un peu spéciale : elle ne fait **absolument rien**. C'est un espace réservé (un *placeholder*).

        *Pourquoi l'utiliser ?* En Python, l'indentation est stricte. Si vous écrivez un `if`, un `else` ou un `for` sans rien mettre à l'intérieur, Python plantera avec une erreur de syntaxe. `pass` permet de dire à l'ordinateur : *"Je n'ai rien à te faire exécuter ici pour le moment, passe ton chemin sans planter"*.

        ```python showLineNumbers
        for i in range(5):
            if i < 3:
                pass  # Code à écrire plus tard, on évite une erreur de syntaxe en attendant
            else:
                print(i)

        # Affiche seulement : 3, 4

        ```

        En résumé :

        * `continue` agit : il force la boucle à sauter le reste du tour actuel pour passer au suivant.

        * `pass` est passif : il ne fait absolument rien et sert uniquement de bouche-trou pour que le code soit syntaxiquement correct.

        :::

        ---

        :::tip Visualisez le changement de trajectoire !
        Ces trois instructions modifient la trajectoire naturelle de votre code. Le meilleur moyen de comprendre la différence entre un `break` et un `continue` est d'exécuter ces exemples en **mode débogage**.

        Placez un point d'arrêt sur le `for` et avancez pas à pas : vous verrez littéralement Python "fuir" la boucle au `break`, ou "rebondir" en haut de la boucle au `continue`.
        :::

    <TabItem value="DRY" label="DRY">

        :::info Éviter la répétition : les boucles et les listes
        En programmation, il existe une règle d'or appelée **DRY** (*Don't Repeat Yourself* - Ne vous répétez pas). 

        Si vous remarquez que vous êtes en train de copier-coller un bloc de code en ne changeant que quelques petites valeurs à l'intérieur, c'est le signal d'alarme : **vous avez besoin d'une boucle !**
        :::

        ---

        :::danger Le code redondant
        Voici un programme qui affiche le bulletin de trois étudiants. Remarquez comment le bloc d'instructions est répété trois fois. Seules les valeurs changent :

        ```python showLineNumbers
        print("Étudiant #1")
        print("Nom : Félix")
        print("Note : 72")
        print()

        print("Étudiant #2")
        print("Nom : Dayron")
        print("Note : 91")
        print()

        print("Étudiant #3")
        print("Nom : Léa")
        print("Note : 58")
        print()

        ```

        Ce code fonctionne, mais c'est un cauchemar à maintenir. Si vous voulez ajouter un 4e étudiant, vous devez copier-coller un nouveau bloc. Pire encore : si vous décidez de changer le mot "Nom :" pour "Prénom :", vous devrez faire la modification à trois endroits différents !
        :::

        ---

        :::note Étape 1 : Extraire ce qui change
        Pour corriger cela, observez les trois blocs et isolez **uniquement ce qui varie** :

        1. Le **numéro** de l'étudiant (`1`, `2`, `3`)
        2. Le **nom** (`Félix`, `Dayron`, `Léa`)
        3. La **note** (`72`, `91`, `58`)

        Le numéro correspond en fait à la position de l'étudiant (l'index `0`, `1`, `2`), auquel on ajoute simplement `1` pour l'affichage humain.
        Quant aux noms et aux notes, on va les extraire du code pour les ranger dans des **listes parallèles** :

        ```python showLineNumbers
        noms  = ["Félix", "Dayron", "Léa"]
        notes = [72, 91, 58]

        ```

        :::

        ---

        :::tip ✅ Étape 2 : La magie de la boucle
        Maintenant que nos données sont proprement rangées dans des listes, on écrit le bloc d'affichage **une seule fois** et on laisse la boucle faire le travail répétitif :

        ```python showLineNumbers
        noms  = ["Félix", "Dayron", "Léa"]
        notes = [72, 91, 58]

        nb_elements = len(noms)
        for i in range(nb_elements):
            print(f"Étudiant #{i + 1}")    # On ajoute 1 à l'index pour afficher 1, 2, 3...
            print(f"Nom : {noms[i]}")      # On pige dans la liste des noms
            print(f"Note : {notes[i]}")    # On pige dans la liste des notes
            print()

        ```

        Le résultat à l'écran est **strictement identique** à la version redondante, mais le code est devenu intelligent !
        :::

        ---

        :::info L'avantage absolu : La flexibilité
        Regardez ce qui se passe si l'on veut ajouter un 4e étudiant (Tristan).
        On ajoute simplement **ses données dans les listes**, et c'est tout. La fonction `len()` détectera automatiquement qu'il y a maintenant 4 éléments, et la boucle s'ajustera toute seule :

        ```python showLineNumbers
        noms  = ["Félix", "Dayron", "Léa", "Tristan"]
        notes = [72, 91, 58, 83]

        nb_elements = len(noms)
        for i in range(nb_elements):
            print(f"Étudiant #{i + 1}")
            print(f"Nom : {noms[i]}")
            print(f"Note : {notes[i]}")
            print()

        ```

        Le corps de la boucle (les lignes 6 à 9) n'a pas changé d'un seul caractère. C'est la véritable puissance de combiner les listes et les boucles : on sépare les **données** de la **logique d'affichage** !
        :::

    <TabItem value="forfor" label="Boucles imbriquées">

        :::info Une boucle dans une boucle : l'imbrication
        Il est tout à fait possible de placer une boucle à l'intérieur d'une autre boucle. On appelle cela des **boucles imbriquées**.\
        C'est la technique incontournable pour traiter des grilles en 2D, comme des pixels sur un écran, un échiquier, ou un tableau Excel (lignes et colonnes).



        Voici un exemple simple avec deux boucles `for` imbriquées pour afficher une table de multiplication :


        ```python showLineNumbers
        for i in range(1, 6):           # Boucle extérieure (gère les lignes)
            for j in range(1, 6):       # Boucle intérieure (gère les colonnes)
                print(i * j, end='\t')  # Affiche le produit avec une tabulation ('\t')
            print()                     # Change de ligne quand la ligne actuelle est finie

        ```

        **L'analogie de l'horloge :**
        Pensez aux aiguilles d'une montre. La boucle intérieure (`j`, les minutes) doit faire un tour complet (de 1 à 5) pour que la boucle extérieure (`i`, les heures) avance d'un seul cran.

        Exécutez ce code en débogage (point d'arrêt ligne 1) pour bien voir `j` tourner à toute vitesse pendant que `i` avance d'un pas lent.

        :::

        ---

        :::tip Une grille dynamique avec `while`
        Dans l'exemple précédent, la grille était carrée. Mais la limite de la boucle intérieure peut très bien **dépendre** de l'état de la boucle extérieure !

        Voici un exemple générant un triangle d'étoiles :

        ```python showLineNumbers
        lignes = 5
        i = 1

        while i <= lignes:           # Boucle extérieure (les lignes)
            j = 1
            while j <= i:            # La limite de j grandit à chaque nouvelle ligne i !
                print('*', end=' ')  # Affiche une étoile sans sauter de ligne
                j += 1
            print()                  # Saute à la ligne suivante
            i += 1

        ```

        Remarquez la condition de la ligne 6 : `while j <= i`. À la ligne 1, la boucle interne affiche 1 étoile et s'arrête. À la ligne 5, elle doit en afficher 5 avant de s'arrêter.
        :::

        ---

        :::note Construire ses lignes d'un coup (Exercice)
        Voici une fonction qui affiche un rectangle de `#` selon des dimensions données en paramètres :

        ```python showLineNumbers
        def afficher_rectangle(largeur, hauteur):
            for i in range(hauteur):          # Répète pour chaque ligne
                for j in range(largeur):      # Répète pour chaque colonne
                    print('#', end='')        # Affiche un '#' collé au précédent
                print()                       # Saute à la ligne
                
        afficher_rectangle(5, 3)

        ```
        *(Affichera un bloc de 3 lignes par 5 colonnes)*

        Toutefois, appeler la fonction `print()` pour chaque petit caractère individuellement demande beaucoup d'efforts à l'ordinateur. Une meilleure approche consiste à **construire la ligne complète en mémoire** à l'aide de la concaténation, puis à l'afficher en une seule fois :

        ```python showLineNumbers
        def afficher_rectangle(largeur, hauteur):
            for _ in range(hauteur):          # Le numéro du tour n'est pas utilisé (_)
                ligne = ''                    # Initialise une boîte vide (chaîne) pour la ligne
                for j in range(largeur):
                    ligne += '#'              # Ajoute les '#' un par un dans la boîte
                print(ligne)                  # Affiche la boîte complète d'un seul coup
                
        afficher_rectangle(5, 3)

        ```

        **Testez-le en débogage :** Observez la variable `ligne` s'allonger petit à petit (`#`, puis `##`, puis `###`) à chaque tour de la boucle intérieure.
        :::

        ---

        :::tip Le "super-pouvoir" Pythonique : multiplier du texte !
        Dans de nombreux langages de programmation, la boucle imbriquée que nous venons de voir est la seule façon de construire cette ligne.

        Mais Python possède une astuce incroyablement performante : **la multiplication de chaînes de caractères**. Vous pouvez éviter complètement la boucle intérieure en multipliant simplement votre caractère :

        ```python showLineNumbers
        def afficher_rectangle_pro(largeur, hauteur):
            for _ in range(hauteur):
                # Crée une ligne de X caractères instantanément !
                print('#' * largeur)  

        ```
        C'est la méthode la plus rapide et la plus élégante en Python pour répéter un motif.\
        Mais vous pouriez aussi utiliser la fonction `join` : 

        ```python showLineNumbers
        def afficher_rectangle_pro(largeur, hauteur):
            for _ in range(hauteur):
            # Crée une ligne de X caractères instantanément !
            print("".join(["#" for _ in range(largeur)]))  

        ```
        :::

        ::::info-nt

        ### La fonction `input()`
        La fonction `input()` rend vos programmes interactifs en permettant de poser une question à l'utilisateur et de récupérer ce qu'il tape au clavier.

        Elle s'utilise généralement en lui passant une chaîne de caractères qui servira de guide (le message d'invite) :

        ```python showLineNumbers
        # Affiche la question, et sauvegarde la réponse dans la variable 'prenom'
        prenom = input("Veuillez saisir votre prénom : ")
        print(f"Bonjour, {prenom} !")

        # On peut aussi l'utiliser sans paramètre, mais l'utilisateur ne saura pas quoi faire !
        saisie_mystere = input() 

        ```

        :::warning `input` met le programme sur PAUSE !
        Lorsque la fonction `input(...)` est exécutée, le programme se met en pause. \
        Dès que Python lit l'instruction `input()`, le programme **se fige**. Il attend patiemment que l'utilisateur tape quelque chose dans la console et appuie sur la touche **ENTRÉE**.\

        C'est donc tout à fait normal que l'instruction suivante ne s'exécute pas tant que la touche Entrée n'a pas été pressée !
        
        :::

        ### Le grand piège : `input()` retourne TOUJOURS du texte !

        La fonction `input(...)` retourne **TOUJOURS** une chaîne de caractères (`str`), même si l’utilisateur saisit un nombre. \
        Pour utiliser la valeur dans un calcul, il faut la convertir avec `int()` ou `float()`.

        Peu importe ce que l'utilisateur tape (même s'il entre le chiffre `42`), la fonction `input()` considère toujours que c'est du texte (`str`). Si vous tentez de faire un calcul mathématique avec cette donnée sans la convertir, le résultat sera inattendu ou le programme plantera.

        Pour utiliser la valeur dans un calcul, il faut la **convertir** en nombre à l'aide des fonctions `int()` (pour un entier) ou `float()` (pour un décimal).

        :::tip Astuce : La conversion sur une seule ligne
        Au lieu de faire la conversion sur deux lignes distinctes, les programmeurs enveloppent souvent le `input()` directement à l'intérieur de `int()` ou `float()` :

        ```python showLineNumbers
        # Demander un nombre entier (int)
        age = int(input("Entrez votre âge : "))
        print(f"Dans 10 ans, vous aurez {age + 10} ans.")

        # Demander un nombre décimal (float)
        taille = float(input("Entrez votre taille en mètres : "))
        print(f"Votre taille en centimètres est {taille * 100} cm.")

        ```

        Sans ces fonctions de conversion, l'ordinateur traiterait l'âge comme le mot "18", et l'addition `age + 10` provoquerait une erreur !
        :::

                0.2 → round: 0.2 → identique
                0.30000000000000004 → round: 0.3 → DIFFÉRENT
                0.4 → round: 0.4 → identique
