                ## Exercices de création

                Pour chacun des exercices de cette section, vous devez créer des fichiers `.py` avec les noms indiqués.

                <DocumentationAutorisee />


                Créez un fichier `cible.py` pour votre réponse.

                Écrivez un programme qui génère des nombres entiers aléatoires entre 1 et 10 **à l'infini**, et qui s'arrête **immédiatement dès qu'il génère un multiple de 7**.

                À chaque tour, le programme doit afficher le nombre généré. 
                Quand la condition d'arrêt est atteinte, il affiche un message de fin indiquant combien de nombres ont été générés au total.

                ✅ **Exemple de sortie** *(les valeurs changeront à chaque exécution)* :
                ```text
                3
                9
                2
                7
                Arrêt après 4 nombres générés.

                ```

                :::tip
                La boucle `while` est idéale ici : on ne sait pas à l'avance combien de tours seront nécessaires !
                Pour compter les tours, utilisez une **variable accumulatrice** (initialisée à 0 avant la boucle).
                :::

                #### Pour aller plus loin

                Modifiez votre programme pour qu'il s'arrête plutôt dès que le **même nombre est généré deux fois de suite**.
                *(Indice : il faudra créer une variable pour mémoriser le nombre tiré au tour précédent !)*

                :::note Notions visées
                Boucle `while` avec condition d'arrêt dynamique, module `random`, variable accumulatrice (compteur), opérateur modulo (`%`).
                :::
                ::::


                ::::info Exercice - Le juste prix (Devinette numérique)
                Créez un fichier `devine.py` pour votre réponse.

                Écrivez un programme qui choisit secrètement un nombre entier aléatoire entre 0 et 100. L'utilisateur doit tenter de deviner ce nombre.

                Tant que la réponse de l'utilisateur est incorrecte, le programme l'aide en lui indiquant si le nombre secret est plus haut ou plus bas. Lorsqu'il trouve le bon nombre, le programme le félicite et s'arrête.

                *Exemples de messages à afficher :* 
                → *"Plus haut !"*
                → *"Plus bas !"*
                → *"Bravo humain, vous avez trouvé le nombre !"*

                :::tip N'oubliez pas la conversion !
                Vous devrez utiliser la fonction `input()` **à l'intérieur** de votre boucle pour demander une nouvelle réponse à chaque tour. 
                Rappelez-vous qu'`input()` retourne toujours du texte (`str`). Vous devrez donc convertir cette réponse en entier avec `int()` pour pouvoir la comparer mathématiquement au nombre secret.
                :::

                :::warning La fonction `input` met le programme sur pause !
                Dès que la fonction `input(...)` est lue, le programme se fige. Il attend que l'utilisateur tape sa réponse et appuie sur la touche ENTRÉE. C'est donc **tout à fait normal** que la boucle s'arrête et attende à chaque tour !
                :::

                :::note Notions visées
                Boucle `while`, module `random`, `input()`, `int()`, structures conditionnelles (`if/elif/else`), condition d'arrêt.
                :::
                ::::
