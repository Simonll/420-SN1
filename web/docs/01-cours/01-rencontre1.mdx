        ## Exercices de compréhension

        Pour les exercices de cette section, vous pouvez écrire vos réponses sur papier ou vous pouvez [créer un fichier *markdown*](/recettes/creer-markdown).

        ::::info Exercice - EXPRESSIONS

        Créez un fichier `r01_expressions.md` pour votre réponse.

        Sans exécuter le code, déterminez le résultat de chacune des expressions ci-dessous.<br />
        Par la suite, tapez (ou copiez) et exécutez le code dans la console, et comparez le résultat avec vos réponses.

        <Row>
            <Column>
                ```python
                2 / 8 - 1 / 8
                ```
                ```python
                (1 + 3) / 4
                ```
            </Column>
            <Column>
                ```python
                2 ** 3
                ```
                ```python
                350 // 100
                ```
            </Column>
            <Column>
                ```python
                "K" + "L"
                ```
                ```python
                "K" + str(45)
                ```
            </Column>
            <Column>
                ```python
                1 / 3
                ```
                ```python
                float(3)
                ```
            </Column>
        </Row>

        La fonction `round()` permet d'arrondir :
        - Le 1er paramètre est la valeur à arrondir.
        - Le 2ème paramètre est le nombre de décimales à conserver.

        Poursuivez l'exercice avec les expressions suivantes :
        <Row>
            <Column>
                ```python
                print(round(1 / 3, 3))
                ```
            </Column>
            <Column>
                ```python
                print(round(2 / 3 + 1, 2))
                ```
            </Column>
        </Row>

        :::note Notions visées
        Opérateurs arithmétiques (`/`, `//`, `**`), priorité des opérations, division entière vs décimale, concaténation de chaînes, `round()`, conversion de types `str()`, `float()`
        :::
