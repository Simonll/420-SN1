        Ces exercices préparent votre environnement de travail. Complétez-les **avant** les exercices de programmation de l'onglet "Activités à faire en classe".

        :::info Devoir #1 — Créer un compte GitHub
        En suivant [cette recette](/recettes/creer-compte-github), créez-vous un compte GitHub si vous n'en avez pas déjà un.
        Vous pouvez utiliser votre adresse courriel personnelle ou celle du Cégep, selon votre préférence.
        :::

        ---

        :::info Devoir #2 — Création des dépôts de code GitHub
        Une fois votre compte GitHub créé, vous devez créer **trois dépôts** distincts :

        1. **General** : Pour vos exercices et exemples vus en classe.
        2. **TP1** : Pour le code de votre premier travail pratique.
        3. **TP2** : Pour le code de votre second travail pratique.

        **Procédure à suivre :**

        1. **Connexion :** Connectez-vous à votre compte sur [github.com](https://www.github.com).
        2. **Création des dépôts :** Suivez [cette recette](/recettes/creer-repertoire-github) pour créer vos trois dépôts avec la nomenclature appropriée.

        | Groupe | Date/Heure | Enseignant | Nomenclature |
        | :--- | :--- | :--- | :--- |
        | 20030 | Vendredi 14h10 | Voir horaire | `a26-gr20030-MATRICULE-PRENOM-NOM` |

        :::note Nomenclature
        Pour votre dépôt **General**, le format est :
        `a26-grXXXX-MATRICULE-PRENOM-NOM` *(ex : a26-gr20030-123456-John-Doe)* où
        `XXXX` est votre numéro de groupe,
        `MATRICULE` votre matricule étudiant,
        `PRENOM` et `NOM` votre prénom et nom de famille (sans accents, séparés par un tiret),
        ajoutez un suffixe pour le type de dépôt (ex : `tp1`, `tp2`).
        :::
