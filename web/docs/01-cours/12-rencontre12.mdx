                ## Exercices de compréhension

                ### Exercice - Broadcasting NumPy

                Créez un fichier `numpy_broadcasting.py` pour votre réponse.

                1. Créez un tableau NumPy 2D de forme (3, 4) contenant des nombres aléatoires entre 0 et 10
                2. Ajoutez un vecteur ligne de 4 éléments à chaque ligne du tableau (broadcasting)
                3. Multipliez chaque colonne par un scalaire différent (utilisez un vecteur colonne)
                4. Affichez le résultat final

                :::note Notions visées
                NumPy, broadcasting, opérations vectorisées, dimensions
                ::::

                ---

                ### Exercice - Filtres et masques avancés

                Créez un fichier `numpy_filtres.py` pour votre réponse.

                1. Générez un tableau NumPy de 1000 nombres aléatoires suivant une loi normale (moyenne=50, écart-type=10)
                2. Créez un masque pour les valeurs comprises entre 40 et 60
                3. Appliquez le masque pour extraire les valeurs dans cette plage
                4. Créez un second masque pour les valeurs en dehors de l'intervalle [30, 70]
                5. Comptez le nombre de valeurs dans chaque catégorie
                6. Utilisez `np.where()` pour créer un tableau indiquant "dans l'intervalle" ou "hors intervalle" selon les valeurs

                :::note Notions visées
                NumPy, masques booléens, `np.where()`, filtrage, `logical_and`, `logical_or`
                ::::

                ---

                ### Exercice - Reshape et manipulation de dimensions

                Créez un fichier `numpy_reshape.py` pour votre réponse.

                1. Créez un tableau NumPy 1D contenant les nombres de 0 à 23
                2. Reshape en un tableau 2D de forme (4, 6)
                3. Reshape en un tableau 3D de forme (2, 3, 4)
                4. Extrayez une "slice" 2D du tableau 3D (ex: la première matrice 2D)
                5. Utilisez `np.vstack()` pour combiner deux tableaux 2D verticalement
                6. Utilisez `np.hstack()` pour combiner deux tableaux 2D horizontalement
                7. Sauvegardez le tableau final dans un fichier `.npy` et le recharger

                :::note Notions visées
                NumPy, `reshape`, `vstack`, `hstack`, `save`, `load`, manipulation de dimensions
                ::::

                ### Exercice - Machine Learning — Régression linéaire simple

                Créez un fichier `ml_regression.py` pour votre réponse.

                1. Générez des données synthétiques : `x` (100 points entre 0 et 10), `y = 2 * x + 1 + bruit` (bruit normal centré réduit)
                2. Utilisez NumPy pour calculer les paramètres d'une régression linéaire simple (pente et intercept) via la méthode des moindres carrés
                3. Tracez les points et la droite de régression avec Matplotlib
                4. Calculez le coefficient de détermination (R²)
                5. Affichez les résultats (pente, intercept, R²)

                :::note Notions visées
                Machine Learning, régression linéaire, moindres carrés, NumPy, Matplotlib
                ::::

                ### Exercice - Machine Learning — Classification simple

                2. Utilisez un algorithme de classification simple (k-NN ou classification par seuil) pour prédire la classe d'un nouveau point
                3. Tracez les points avec des couleurs différentes pour chaque classe
                4. Marquez le nouveau point à classifier avec une couleur/marker différent

                :::note Notions visées
                Machine Learning, classification, k-NN, visualisation de classes
