                ## Exercices de compréhension

                ### Exercice - Manipulation de set

                Créez un fichier `set_manipulation.py` pour votre réponse.

                À partir des ensembles suivants :

                ```python
                ensemble1 = {1, 2, 3, 4, 5}
                ensemble2 = {4, 5, 6, 7, 8}
                ```

                Créez 3 nouveaux ensembles et complétez 1 cas de conversion :

                1. Union des deux ensembles → `{1, 2, 3, 4, 5, 6, 7, 8}`
                2. Intersection des deux ensembles → `{4, 5}`
                3. Différence ensemble1 - ensemble2 → `{1, 2, 3}`
                4. La liste suivante contient des doublons. Convertissez-la en ensemble pour les supprimer, puis reconvertissez-la en liste triée.

                   ```python
                   mesures = [3, 7, 3, 1, 7, 9, 1, 5]
                   ```
                   Résultat attendu : `[1, 3, 5, 7, 9]`

                :::note Notions visées
                Ensembles (`set`), union, intersection, différence, conversion `list()` / `sorted()`
                ::::

                ### Exercice - Tuples et données immuables

                Créez un fichier `tuple_exercice.py` pour votre réponse.

                Un tuple est une collection **immuable** qui peut contenir des données de types différents.

                ```python
                coordonnee = (45.5, -73.5, "Montreal")
                ```

                Écrivez un programme qui :
                1. Affiche chaque élément du tuple sur une ligne séparée avec un label
                2. Tente de modifier le 3e élément (ça doit lever une erreur — c'est normal!)
                3. Créez un nouveau tuple avec les mêmes données mais avec un quatrième élément (ex: "Canada")

                :::note Notions visées
                Tuples, immuabilité, accès par index, unpacking
                ::::

                ### Exercice - Dictionnaires

                Créez un fichier `dictionnaire_exercice.py` pour votre réponse.

                Les données de température d'une journée d'une ville sont stockées sous forme de dictionnaire.

                ```python
                info = {
                    "lieu": "Raccoon City",
                    "date": "2025-07-12",
                    "temperatures_C": {
                        "Matin": 18.2,
                        "Midi": 22.5,
                        "Après-midi": 24.1,
                        "Soir": 20.3
                    }
                }
                ```

                Écrivez un programme qui :
                1. Affiche le lieu et la date en en-tête.
                2. Affiche chaque moment de la journée avec sa température, alignés en colonnes.
                3. Calcule et affiche la température moyenne.

                Résultat attendu :

                ```
                Températures à Raccoon City le 2025-07-12

                    Matin       : 18.2 °C
                    Midi        : 22.5 °C
                    Après-midi  : 24.1 °C
                    Soir        : 20.3 °C

                Température moyenne : 21.275 °C
                ```

                :::note Notions visées
                Dictionnaires imbriqués, accès par clé, `.items()`, calcul de moyenne, f-strings
                ::::

                ### Exercice - Compréhension de liste

                Créez un fichier `comprehension_liste.py` pour votre réponse.

                À partir de la liste suivante :

                ```python
                liste = [1, 2, 3, 4, 5]
                ```

                Créez 6 nouvelles listes en utilisant **exclusivement la compréhension de liste** :

                1. Multiplier chaque élément par 5 → `[5, 10, 15, 20, 25]`
                2. Garder uniquement les nombres supérieurs à 2 → `[3, 4, 5]`
                3. Créer une liste de booléens indiquant si chaque nombre est supérieur à 3 → `[False, False, False, True, True]`
                4. Créer une nouvelle liste contenant les carrés sous forme de texte → `['Le carré de 1 est 1', ..., 'Le carré de 5 est 25']`
                5. Remplacer les nombres impairs par le mot "impair" → `['impair', 2, 'impair', 4, 'impair']`
                6. Doubler uniquement les nombres pairs → `[4, 8]`

                :::note Notions visées
                Compréhension de liste, filtrage (`if`), transformation (`expression`), if/else compact, f-strings
                ::::
