### Révision — Propriétés théoriques de Pandas / NumPy / IA (papier)

**Matériel autorisé :** aucune documentation, aucun ordinateur.

L'examen étant **100 % papier**, on ne peut pas exécuter Pandas/NumPy/Matplotlib. On évalue donc les **propriétés théoriques** (concepts et prédiction de sortie) :

**Pandas (concepts + prédiction de sortie)**
- `DataFrame` vs `Series` ; `loc` (étiquettes) vs `iloc` (positions entières) ; attributs `shape`, `dtypes`, `columns`
- Filtrage booléen : combiner des conditions (`&`, `|`, `~`, parenthèses), erreur « ambiguous truth value »
- Nettoyage : `dropna()` vs `fillna()`, `drop_duplicates()`
- Transformation : nouvelles colonnes, `apply()`, `map()`
- Agrégation : structure de la sortie d'un `groupby()`, `.mean()/sum()/count()`
- Fichiers : `read_csv()`/`to_csv()`, `read_json()`/`to_json()`
- Type de question : « quelle est la sortie de ce code ? » sur un petit DataFrame

**NumPy (théorie + calcul à la main)**
- `shape`/`ndim`/`dtype`/`size` ; opérations vectorisées (élément par élément)
- Masques booléens `arr[arr > 5]` ; `np.where()`
- Broadcasting (prédire la forme résultante) ; `reshape` ; `transpose` ; sauvegarde `.npy`
- Statistiques : `mean`, `std`, `min`, `max`, `sum`

**IA (conceptuel)**
- IA vs Machine Learning vs Deep Learning (hiérarchie)
- Supervisé vs non supervisé ; **régression vs classification** (exemples)
- Vocabulaire : `feature`, `label`, modèle, entraînement, inférence
- Sur-apprentissage vs sous-apprentissage ; **exactitude (accuracy)**
- Empreinte écologique de l'IA

:::note
Toutes ces propriétés sont détaillées dans l'onglet **« Théorie — Examen papier »** de la rencontre R13. Ici, concentrez la révision sur les notions où vous hésitez encore.
:::
