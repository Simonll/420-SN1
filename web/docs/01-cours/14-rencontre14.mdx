### Révision — Volet ordinateur (Pandas + Matplotlib)

**Matériel autorisé :** ordinateur, documentation locale du cours, Python/Pandas/Matplotlib.

**Préparez-vous en révisant :**

1. **Fichiers CSV avec Pandas** :
   - `read_csv()` — paramètres importants (delimiter, header, etc.)
   - `to_csv()` — exportation
   - Exploration (`info()`, `dtypes`, `describe()`, `head()`, `shape`)
   - Sélection (`loc`, `iloc`)
   - Filtres booléens (conditions simples et complexes)
   - Tri (`sort_values()`)
   - Nettoyage (`dropna()`, `fillna()`, `drop_duplicates()`)
   - Transformation (nouvelles colonnes, `apply()`, `map()`)
   - Agrégations (`groupby()`, `mean()`, `sum()`, `count()`)

2. **Fichiers JSON avec Pandas** :
   - `read_json()` — lecture
   - `to_json()` — écriture

3. **Graphiques sans Pandas (Matplotlib)** :
   - Création de graphiques depuis tableaux NumPy ou listes
   - `plot()`, `scatter()`, `bar()`, `hist()`
   - Personnalisation (`title`, `xlabel`, `ylabel`, `legend`, `grid`, `savefig`)
   - Sauvegarde des graphiques

4. **Synthèse** :
   - Combiner toutes les notions dans un projet complet (comme l'exercice de synthèse de R13)
