        ## Durée de l'examen : 120 minutes
        ## L'examen est **entièrement sur papier — sans ordinateur, sans documentation**

        ### Structure (20 points)

        | Section | Format | Points |
        |---|---|---|
        | **A. Choix multiples** | 40 QCM (R1→R13, dont théorie Pandas/NumPy/IA) × 0,25 | 10 |
        | **B. Trace d'exécution** | tableau à compléter (boucle `for`) | 2 |
        | **C. Écriture de code** | programme (filtre, moyenne, max) | 3 |
        | **D. Correction de code** | trouver 3 erreurs | 3 |
        | **E. Notions + code à compléter** | définition de diagramme + snippets (TP1/TP2) | 2 |

        **Il n'y a AUCUN volet sur ordinateur.** Tout se fait au crayon sur papier.

        ### Détail des sections

        - **40 QCM** : une seule réponse, on encercle la bonne lettre (variables, types, conditions, boucles, listes, dict, set, fichiers, Pandas, NumPy, IA).
        - **Trace** : compléter le tableau ligne par ligne (comme en classe).
        - **Écriture de code** : aucun module, aucune bibliothèque (Matplotlib, Pandas, NumPy…) — algorithmes de base par cœur.
        - **Correction de code** : identifier et corriger 3 erreurs dans un extrait.
        - **Code à compléter** : remplir les mots manquants dans un snippet (boucle, `return`, `pd.read_csv`, `bins=`, `plt.bar`/`plt.hist`).
