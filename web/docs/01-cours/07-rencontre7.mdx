# Rencontre 7 — Finalisation TP1 & Examen Formatif

<Tabs queryString="onglet">

    <TabItem value="tp1" label="1. Finalisation & Remise du TP1" default>

        :::info Remise officielle du TP1
        La première partie de cette rencontre est consacrée à la **finalisation de votre TP1** en classe.

        - **Remise** : Votre code doit être poussé (*push*) sur votre dépôt GitHub **ce soir avant minuit**.
        - **Vérifications finales** :
          - Assurez-vous d'avoir au moins **5 commits** significatifs.
          - Vérifiez que chaque fonction dans `cinetique.py` et `analyse.py` possède un **docstring** complet.
          - Exécutez une dernière fois `main.py` pour vous assurer qu'il n'y a aucune erreur d'exécution.
        :::

    </TabItem>

    <TabItem value="formatif" label="2. Examen Intra Formatif">

        :::info Simulation sous contraintes réelles
        Pour vous préparer à l'**Examen Intra Sommatif (Rencontre 8)**, la seconde partie de la période est consacrée à un examen formatif.

        ### **Déroulement**
        - **Premières heures** : Simulation en conditions d'examen (sans Internet, avec documentation locale du cours).
        - **Dernière heure** : Correction collective et retour sur les notions les plus exigeantes.

        ### **Notions couvertes à l'examen (R1 à R6)**
        - Variables, types et expressions mathématiques
        - Création de fonctions (`def`, `return`, paramètres)
        - Structures conditionnelles (`if / elif / else`)
        - Boucles (`while`, `for`, `range`) et parcours de listes
        :::

    </TabItem>
