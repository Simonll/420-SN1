                Créez un fichier `jeu_devinette_ameliore.py` pour votre réponse.

                Partez du code suivant (version de base du jeu de devinette) et **améliorez-le** afin d'insulter gentiment l'utilisateur s'il saisit un nombre déjà saisi.                 Malgré sa stupidité, vous devez quand même lui indiquer si la bonne réponse est plus haute ou plus basse!
