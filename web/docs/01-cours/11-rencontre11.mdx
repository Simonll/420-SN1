                ## Exercices de compréhension

                ### Exercice - Création et inspection d'un tableau NumPy

                Créez un fichier `numpy_creation.py` pour votre réponse.

                1. Créez un tableau NumPy contenant les nombres de 0 à 9
                2. Affichez la forme (`shape`) du tableau
                3. Affichez le type de données (`dtype`)
                4. Affichez le nombre de dimensions (`ndim`)
                5. Affichez la taille (`size`)
                6. Créez un second tableau 2D de forme (3, 4) rempli de zéros
                7. Affichez sa forme et son type

                :::note Notions visées
                NumPy, `array`, `shape`, `dtype`, `ndim`, `size`, `zeros`, `arange`
                ::::

                ---

                ### Exercice - Indexation et slicing NumPy

                Créez un fichier `numpy_indexation.py` pour votre réponse.

                1. Créez un tableau NumPy 2D de forme (4, 5) contenant des nombres de 0 à 19 (utilisez `arange` et `reshape`)
                2. Affichez le terme à la position (2, 3)
                3. Affichez la première ligne
                4. Affichez la dernière colonne
                5. Affichez le sous-tableau formé par les 2 premières lignes et les 3 premières colonnes
                6. Modifiez la valeur à la position (1, 2) pour qu'elle soit égale à 99
                7. Affichez le tableau modifié

                :::note Notions visées
                NumPy, indexation, slicing, `reshape`, `arange`, modification d'éléments
                ::::

                ---

                ### Exercice - Opérations vectorisées sur tableaux

                Créez un fichier `numpy_vectorisation.py` pour votre réponse.

                1. Créez un tableau NumPy `a` contenant `[1, 2, 3, 4, 5]`
                2. Créez un tableau NumPy `b` contenant `[10, 20, 30, 40, 50]`
                3. Calculez et affichez la somme élément par élément (`a + b`)
                4. Calculez et affichez le produit élément par élément (`a * b`)
                5. Calculez et affichez `a` élevé au carré (`a ** 2`)
                6. Calculez et affichez la moyenne de `a`
                7. Calculez et affichez le maximum de `b`
                8. Créez un masque booléen pour `a` : les éléments supérieurs à 3
                9. Appliquez le masque pour afficher uniquement les éléments correspondants

                :::note Notions visées
                NumPy, opérations vectorisées, broadcasting, fonctions statistiques (`mean`, `max`), masques booléens
                ::::

                ---

                ### Exercice - Intégration NumPy + Matplotlib

                Créez un fichier `numpy_matplotlib.py` pour votre réponse.

                1. Créez un tableau NumPy `x` contenant 100 points équidistants entre 0 et 2π
                2. Créez un tableau NumPy `y` contenant `sin(x)`
                3. Tracez le graphique de `y` en fonction de `x` avec Matplotlib
                4. Ajoutez un titre, des labels aux axes, et une grille
                5. Sauvegardez le graphique dans un fichier `courbe_sinus.png`

                Résultat attendu : un graphique de la fonction sinus avec titre, axes labellisés et grille.

                :::note Notions visées
                NumPy, `linspace`, fonctions trigonométriques, Matplotlib, `plot`, `title`, `xlabel`, `ylabel`, `grid`, `savefig`
                ::::

                ---

                ### Exercice - Histogramme avec NumPy et Matplotlib

                Créez un fichier `numpy_histogramme.py` pour votre réponse.

                1. Générez 1000 nombres aléatoires suivant une loi normale (moyenne=0, écart-type=1) avec NumPy
                2. Affichez quelques statistiques descriptives (moyenne, écart-type, min, max)
                3. Tracez un histogramme de ces données avec Matplotlib (20 bins)
                4. Ajoutez titre et labels
                5. Sauvegardez le graphique dans `histogramme.png`

                :::note Notions visées
                NumPy, `random.normal`, statistiques descriptives, Matplotlib, `hist`, histogramme
                ::::

                ---

                ### Exercice - Scatter plot avec NumPy

                Créez un fichier `numpy_scatter.py` pour votre réponse.

                1. Générez 50 points aléatoires pour `x` (uniforme entre 0 et 10)
                2. Générez `y` comme `2 * x + 1 + bruit` où le bruit est une normale centrée réduite
                3. Tracez un scatter plot des points (x, y)
                4. Ajoutez titre et labels
                5. Sauvegardez le graphique dans `scatter.png`

                :::note Notions visées
                NumPy, `random.uniform`, `random.normal`, Matplotlib, `scatter`, scatter plot
