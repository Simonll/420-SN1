                ::::info Exercice - NumPy vs boucles
                📁 Créez un fichier `r10_numpy_vs_boucles.py` pour votre réponse.

                Un physicien calcule la vitesse finale de 10 000 000 objets à l'aide de la formule

                $$
                v \quad = \quad v_0 + a \cdot t,
                $$

                où :
                - $v_0 = 5.0$ m/s est la vitesse initiale (la même pour tous les objets)
                - $a$ est l'accélération propre à chaque objet (chargée depuis un fichier)
                - $t = 3.0$ s est le temps écoulé (le même pour tous les objets)

                Par exemple, pour le premier objet ($a = 4.1$ m/s²) :

                $$
                \begin{aligned}
                v \quad &= \quad 5.0 + 4.1 \times 3.0 \\
                  &= \quad 17.3 \ \text{m/s}
                \end{aligned}
                $$

                Téléchargez le fichier <a href={useBaseUrl('/ressources/npy/accelerations.npy')} download="accelerations.npy">`accelerations.npy`</a> et placez-le dans le même répertoire que votre script.

                :::warning ⚠️ Ne pas committer `accelerations.npy`
                Ce fichier pèse ~70 Mo et ne doit pas être ajouté à GitHub.\
                Ajoutez-le à votre `.gitignore` :
                ```
                accelerations.npy
                ```
                ou encore, pour carrément exclure tous les fichiers se terminant par `.npy` :
                ```
                *.npy
                ```
                :::

                Utilisez le code suivant pour charger les données sous deux formes :

                ```python
                import numpy as np
                import time

                accelerations_np   = np.load("accelerations.npy")  # tableau NumPy
                accelerations_list = list(accelerations_np)        # liste Python
                ```

                **Calcul des vitesses**

                1. Calculez les vitesses finales **avec une boucle Python** (à partir de `accelerations_list`) et mesurez le temps d'exécution avec `time.time()`.
                2. Calculez les vitesses finales **avec NumPy** (sans boucle, à partir de `accelerations_np`) et mesurez le temps d'exécution.
                3. Avec **NumPy**, calculez :
                    - la vitesse finale minimale, maximale et moyenne parmi les 10 millions d'objets.
                    - les 3 premières accélérations et les 3 premières vitesses finales calculées.
                    - l'indice de la vitesse finale la plus élevée.
                4. Affichez les résultats en respectant le format suivant :

                ```
                Temps d'exécution
                    - Solution avec boucle : 1.35896015 secondes
                    - Solution avec NumPy  : 0.14341521 secondes

                Statistiques sur les vitesses finales
                    - minimum : 6.5
                    - maximum : 35.0
                    - moyenne : 20.74975367

                Détails
                    - Les 3 premières accélérations : [4.1 9.5 7.5]
                    - Les 3 premières vitesses finales calculées : [17.3 33.5 27.5]
                    - Indice de la vitesse finale la plus élevée : 531
                ```

                :::note Notions visées
                Opérateurs arithmétiques vectorisés, NumPy vs boucles Python, fonctions d'agrégation

                ::::info Exercice - Traitement des pixels
                📁 Créez un fichier `r10_traitement_pixels.py` pour votre réponse.

                Un système de traitement d'images reçoit des valeurs de pixels brutes qui peuvent dépasser les limites valides `[0, 255]`. Le pipeline de traitement se déroule en trois phases : d'abord **détecter et corriger** les valeurs invalides, puis **normaliser** les pixels entre 0 et 1, et enfin **binariser** l'image en noir et blanc.

                ```python
                pixels = np.array([-30, 0, 85, 128, 260, 300, 72, -5, 200, 255])
                ```

                **Transformation**

                5. Ramenez les pixels dans l'intervalle `[0.0, 1.0]` en divisant chaque valeur par 255 (0 reste 0, 255 devient 1.0).
                6. Convertissez chaque pixel en noir ou blanc : les valeurs inférieures à `0.5` deviennent `0.0` (noir) et les autres deviennent `1.0` (blanc).

                plt.title("Graphique de la fonction y = x^2")
                plt.xlabel("x")
                plt.ylabel("y")
                plt.grid()
                plt.legend()

                plt.show()
