---

Un environnement virtuel est une "bulle" isolée qui contient une version spécifique de Python et les bibliothèques nécessaires pour un projet. C'est une pratique essentielle pour éviter les conflits entre les dépendances de différents projets.

---

## Méthode 1 : L'approche visuelle (Recommandée)

L'extension officielle Python de Microsoft intègre un outil automatisé qui s'occupe de tout en arrière-plan. C'est la méthode la plus fluide pour éviter les erreurs de syntaxe dans le terminal.

1.  **Ouvrir la palette de commandes**
    Utilisez le raccourci <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (ou <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> sur Mac).

2.  **Lancer l'outil de création**
    Tapez `Python: Create Environment` (ou `Python : Créer un environnement`) et sélectionnez cette option dans le menu déroulant.

3.  **Choisir le type d'environnement**
    VS Code vous demandera de choisir entre `Venv` et `Conda`. Pour le cours, choisissez **Venv**, qui est le standard intégré directement dans Python.

4.  **Sélectionner l'interpréteur**
    Sélectionnez la version de Python à utiliser (ex: Python 3.11 ou 3.12).

    <Admonition type="info">
    S'il y a un fichier `requirements.txt` dans le dossier, VS Code proposera même d'installer les dépendances automatiquement !
    </Admonition>

VS Code va alors créer un dossier `.venv` dans l'explorateur de fichiers à gauche. Une fois terminé, une petite notification apparaîtra en bas à droite pour confirmer que l'environnement est actif.

---

## Méthode 2 : L'approche par le terminal

Pour les étudiants qui se dirigent vers l'ingénierie et qui auront besoin de comprendre comment les choses fonctionnent "sous le capot", la commande manuelle est un incontournable.

1.  Ouvrez un terminal intégré dans VS Code (<kbd>Ctrl</kbd> + <kbd>\`</kbd>).
2.  Tapez la commande suivante pour créer l'environnement (le deuxième `.venv` est le nom du dossier qui sera créé) :
    ```bash
    python -m venv .venv
    ```
    <Admonition type="note">
    Sur Mac ou Linux, il faut souvent taper `python3 -m venv .venv`.
    </Admonition>
3.  VS Code détectera généralement qu'un nouvel environnement a été créé et affichera une boîte de dialogue demandant : "We noticed a new environment has been created. Do you want to select it for the workspace folder?". Il suffit de cliquer sur **Yes**.
