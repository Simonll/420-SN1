# 🔒 Créer un compte GitHub

GitHub sert à créer des répertoires de code. C'est exactement la même chose qu'un répertoire (ou dossier) sur votre ordinateur, à la différence que vous avez accès au contenu de ce répertoire à partir de n'importe où dans le monde.

Tout le code que vous allez créer dans le cours sera déposé dans des répertoires sur GitHub.

[github.com](https://github.com) est sans doute le site le plus courant pour stocker des projets de code.

Il est probable que vous utilisiez ce site quand vous coderez des projets, quelque soit votre discipline.

:::info-nt
Pour créer un compte GitHub, suivez les étapes suivantes :
1. Allez sur [github.com](https://github.com).
2. Cliquez sur "Sign up".
3. Saisissez votre adresse courriel, un nom d'utilisateur et un mot de passe.
4. Cliquez sur "Create account".
5. Ouvrez vos courriels et récupérez le code de vérification.
6. Saisissez le code de vérification dans le formulaire d'inscription.
7. Cliquez sur "Continue".
8. Tentez de vous connecter.
:::

## Si le vidéo YouTube est inaccessible

Si votre établissement bloque YouTube ou si la vidéo n'est pas disponible, vous pouvez suivre ces étapes textuelles :

1. Allez sur [github.com](https://github.com).
2. Cliquez sur "Sign up" en haut à droite.
3. Saisissez :
   - **Email** : votre adresse courriel personnelle
   - **Password** : un mot de passe fort (au moins 12 caractères, avec des lettres, chiffres et symboles)
   - **Username** : un nom d'utilisateur unique (ex: `prenom.nom`)
4. Cliquez sur "Create account".
5. GitHub vous enverra un code de vérification à votre courriel. Ouvrez votre messagerie, récupérez le code et saisissez-le sur la page de vérification.
6. Répondez aux questions supplémentaires (planification, expérience, etc.) ou cliquez sur "Skip" pour passer à l'étape suivante.
7. Une fois votre compte créé, vous pouvez vous connecter et créer votre premier répertoire. [Voir la recette Créer un répertoire GitHub](/recettes/creer-repertoire-github).

---

## Conseil de sécurité

- **N'utilisez pas votre mot de passe Courriel du Cégep** pour GitHub.
- Activez l'authentification à deux facteurs (2FA) dans les paramètres de votre compte pour une sécurité accrue.
