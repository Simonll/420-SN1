# 📝 Fichier Markdown

Les fichiers **Markdown** (`.md`) permettent d’écrire du texte structuré, lisible à la fois par les humains et les machines.
Ils sont souvent utilisés pour la documentation, les notes, ou les fichiers `README`.

---

## Créer un fichier Markdown

<Row>
<Column>

### PyCharm

1. Ouvrir un projet dans PyCharm (ou en [créer un nouveau](creer-projet)).
2. Dans l’arborescence à gauche, cliquer-droit sur le dossier où créer le fichier.
3. Choisir **New > File**.
4. Nommer le fichier avec l’extension `.md`, par exemple `notes.md`, puis appuyer sur ⏎.
5. Un nouvel onglet s’ouvre avec un éditeur Markdown.

</Column>
<Column>

### VS Code

1. Ouvrir le dossier du projet dans VS Code (File > Open Folder ou Ctrl+K Ctrl+O).
2. Dans l'explorateur à gauche (Ctrl+B pour afficher/cacher), cliquer-droit sur le dossier où créer le fichier.
3. Choisir **New File**.
4. Nommer le fichier avec l'extension `.md`, par exemple `notes.md`, puis appuyer sur ⏎.
5. Un nouvel onglet s'ouvre avec l'éditeur Markdown.

</Column>
</Row>

---

## Prévisualiser le fichier Markdown

<Row>
<Column>

### PyCharm

1. Dans la barre d’outils du haut, cliquer sur l’icône de `Editor and Preview` (des lignes et un rectangle).
2. PyCharm affiche à gauche le texte brut (code source), et à droite le rendu visuel.

</Column>
<Column>

### VS Code

1. Avec le fichier `.md` ouvert, utiliser le raccourci **Ctrl+Shift+V** (ou Cmd+Shift+V sur Mac).
2. VS Code ouvre un nouvel onglet avec l'aperçu de rendu à côté de l'éditeur.
3. Alternatively, cliquer sur l'icône de `Preview` (œil) en haut à droite du fichier.

</Column>
</Row>

## Écrire du contenu Markdown

<Row>
<Column>

### PyCharm

1. Taper du texte dans le fichier (à gauche) en utilisant la syntaxe [Markdown](https://www.markdownguide.org/basic-syntax/).
2. Ajouter des titres, des listes, des liens, des images ou des blocs de code (voir exemples ci-dessous).
3. Le rendu visuel à droite se met à jour automatiquement.

</Column>
<Column>

### VS Code

1. Taper du texte en utilisant la syntaxe [Markdown](https://www.markdownguide.org/basic-syntax/).
2. Ajouter des titres, des listes, des liens, des images ou des blocs de code (voir exemples ci-dessous).
3. L'aperçu (onglet de droite) se met à jour en temps réel à mesure que vous tapez.
4. Utiliser **Ctrl+F** dans l'aperçu pour chercher du texte dans le rendu.

</Column>
</Row>

<Row>
<Column>

    :::info Exemple de contenu Markdown

````markdown
# Mes notes

Voici une **liste de tâches** :

- Lire la documentation
- Écrire un `README.md`
- Apprendre Markdown

## Exemple de lien

[Doc](https://www.markdownguide.org)

## Exemple de code

```python
def dire_bonjour(nom):
    print(f"Bonjour, {nom}!")
```
````

    :::

</Column>

## Faire une trace

Pour faire le tableau d'une trace de l'exécution d'un bout de code, il suffit d'utiliser des `|` pour séparer les colonnes et `-` pour créer une ligne horizontale.

<Row>
<Column>

    :::info Exemple de tableau de trace

````markdown
| # ligne | a | b  | affichage |
|---------|---|----|-----------|
| 1       | 7 |    |           |
| 2       | 7 | 14 |           |
| 3       | 7 | 14 | salut 14  |
````

(vous pouvez copier-coller ce gabarit dans votre fichier Markdown)

    :::

</Column>
<Column>

:::tip Résultat affiché

| 2       | 7 | 14 |           |
| 3       | 7 | 14 | salut 14  |

    :::

</Column>
</Row>

## Astuces

- Pour insérer des images locales, utiliser la syntaxe `![texte alternatif](chemin/vers/image.png)`.
