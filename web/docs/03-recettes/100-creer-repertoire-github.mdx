# 📥 Créer un répertoire GitHub

:::info-nt

1. Allez sur [github.com](https://github.com)
2. Connectez-vous à votre compte
3. Cliquez sur l'onglet `Repositories`
4. Cliquez sur le bouton `New` en haut à droite
5. (Optionnel) Ajoutez un fichier `README.md`, un `.gitignore` et choisissez une licence
6. Donnez un nom à votre nouveau répertoire, par exemple `Cours_420-SN1`
7. Dans `Configuration` > `Choose visibility`, sélectionnez `Private` pour que vos fichiers **ne soient pas publics** (accessibles par tout le monde)
8. Cliquez sur `Create repository`

:::

---

## Après la création

Une fois le répertoire créé, vous devrez le cloner sur votre ordinateur pour pouvoir travailler dans vos fichiers localement.

- Si vous utilisez **PyCharm** : voir la recette [Cloner avec PyCharm](/recettes/enclasse_pycharm#1-cloner-un-répertoire-github)
- Si vous utilisez **GitHub Desktop** : voir la recette [Autres recettes](/recettes/autres-recettes?onglet=git-avec-github-desktop#2-ouvrir-un-projet-dans-pycharm)

---

## Pourquoi un répertoire privé ?

- Vos travaux sont protégés : seuls vous et les personnes autorisées (votre enseignant) pouvez y accéder.
- Vous pouvez travailler à plusieurs sur le même projet sans exposer votre code au public.
- GitHub offre des fonctionnalités de collaboration (issues, pull requests) même pour les dépôts privés.
