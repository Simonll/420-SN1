# Créer un projet dans VS Code

Un **projet VS Code** est un dossier contenant tous les fichiers liés à un programme Python. \\
Il contient habituellement :

- des fichiers `.py` (code Python)
- un environnement virtuel (`.venv`) pour gérer les dépendances
- d'autres fichiers comme des notebooks Jupyter, des images, ou des fichiers Markdown

---

## Deux façons de démarrer un projet

### À partir d'un répertoire GitHub existant

*(si un projet est déjà ouvert, cliquer sur **File > New Window** pour ouvrir le nouveau projet dans un nouvel onglet)*

1. Créer un dépôt GitHub (si ce n'est pas déjà fait) et le cloner sur votre ordinateur. [Voir la recette](/recettes/creer-repertoire-github).
2. Ouvrir **VS Code**.
3. Sur l'écran d'accueil, cliquer sur **Open Folder** et sélectionner le dossier cloné.

<!-- ![Open Folder](./img/recettes/vscode-open-folder.png) -->

### À partir d'un nouveau projet vide

*(si un projet est déjà ouvert, cliquer sur **File > New Window** pour ouvrir le nouveau projet dans un nouvel onglet)*

1. Ouvrir **VS Code**.
2. Sur l'écran d'accueil, cliquer sur **Open Folder** et sélectionner un dossier vide ou créer un nouveau dossier (sur votre bureau par exemple).

---

## Cloner un dépôt GitHub localement

Si vous avez créé un dépôt GitHub et que vous souhaitez récupérer (cloner) sur votre ordinateur, suivez ces étapes :

### Obtenir l'URL du dépôt

1. Allez sur votre dépôt sur [github.com](https://github.com).
2. Cliquez sur le bouton **Code** (vert, en haut à droite).
3. Sélectionnez l'onglet **HTTPS** (par défaut).
4. Copiez l'URL (elle ressemble à `https://github.com/votre-utilisateur/nom-depot.git`).

### Cloner avec VS Code

**Méthode 1 : Terminal intégré de VS Code**

1. Ouvrir **VS Code**.
2. Ouvrir le terminal intégré : **Terminal > New Terminal** (ou Ctrl+`).
3. Naviguer vers le dossier où vous voulez stocker le projet (par exemple `Desktop`) :
   ```bash
   cd ~/Desktop
   ```
4. Taper la commande de clonage avec l'URL copiée :
   ```bash
   git clone https://github.com/votre-utilisateur/nom-depot.git
   ```
5. Appuyer sur ⏎.
6. Un dossier portant le nom du dépôt est créé. Ouvrir ce dossier avec **File > Open Folder**.

**Méthode 2 : Commande `git clone` depuis le terminal de votre ordinateur**

1. Ouvrir un terminal (ou PowerShell sur Windows).
2. Naviguer vers le dossier où vous voulez stocker le projet :
   ```bash
   cd ~/Desktop
   ```
3. Cloner le dépôt :
   ```bash
   git clone https://github.com/votre-utilisateur/nom-depot.git
   ```
4. Une fois le clonage terminé, ouvrir VS Code, puis **File > Open Folder** et sélectionner le dossier créé.

### Après le clonage

Une fois le dépôt cloné :

- Le dossier contient tous les fichiers du dépôt GitHub.
- L'historique Git est conservé (vous pouvez voir les commits antérieurs avec `git log`).
- VS Code détecte automatiquement que c'est un dépôt Git et affiche les informations Git dans la barre de statut (en bas à droite).

## Comprendre la structure du projet

Une fois le projet créé, VS Code affiche :

- un dossier principal (nom du projet)
- un dossier `.venv` contenant l'environnement virtuel (après activation, voir la recette [Créer un environnement virtuel](/recettes/creer-venv-vscode))
- un dossier `data` contenant des fichiers de données (optionnel)
- un dossier `notebooks` contenant les notebooks Jupyter (optionnel)
- un dossier `src` contenant le code source (optionnel)
- un fichier `main.py` (optionnel)

---

## Ajouter un premier fichier

1. Dans la colonne de gauche, cliquer-droit sur le dossier du projet (ou sur le dossier `src` si vous l'avez créé), puis choisir **New File**.
2. Donner un nom au fichier (ex : `test.py`) et appuyer sur ⏎.
3. Un nouveau fichier `test.py` est créé et s'ouvre dans un nouvel onglet.

Pour plus de détails sur la création de fichiers Python, voir la recette [Créer un fichier Python](/recettes/creer-python).

## Créer un environnement virtuel

Un **environnement virtuel** est une "bulle" isolée pour votre projet. Il contient sa propre installation de Python et ses propres bibliothèques (comme Matplotlib, Pandas, etc.), ce qui évite les conflits entre les différents projets sur votre machine.

Pour créer un environnement virtuel dans VS Code, voir la recette [Créer un environnement virtuel dans VS Code](/recettes/creer-venv-vscode).

---

## Astuces

- Toujours créer un projet avant d'écrire du code, pour bien organiser vos fichiers.
- Éviter les accents, espaces ou caractères spéciaux dans les noms de dossiers (utilisez des tirets bas `_` ou des tirets `-` à la place).
- Le projet peut contenir aussi des notebooks Jupyter, des fichiers Markdown, etc.
- Si vous utilisez PyCharm au lieu de VS Code, voir la recette [Créer un projet PyCharm](/recettes/creer-projet).
