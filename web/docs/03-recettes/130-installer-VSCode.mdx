# Installer VS Code


*VS Code* est le logiciel qui va nous servir pour coder en Python. \
Il est gratuit et est l'un des logiciels de référence dans l'industrie pour le langage Python.

Pour installer VS Code à la maison :

1. Aller sur le site de [VS Code](https://code.visualstudio.com/download).
2. Télécharger la version appropriée pour votre système d'exploitation.
3. Double-cliquer sur le fichier de téléchargement.
4. Suivre les instructions d'installation et cocher les options suivants :
    - *Add to PATH*, afin d'avoir accès à VS Code depuis le terminal.
    - *Create Desktop Shortcut / VS Code*, afin de créer un raccourci de l'application sur votre bureau.

## Tester l'installation de VS Code

1. Lancer VS Code.
2. [Créer un nouveau projet.](creer-projet)
3. Créer un nouveau fichier Python.
4. Écrire un petit programme et le rouler, par exemple :

```python
print("Hello world")
```
5. Exécuter le programme.

Vous devriez voir dans le bas de VS Code sur fond noir, le message "Hello world" apparaitre. \
Si c'est bien le cas, votre installation est fonctionnelle.

## Ajouter des extensions à VS Code

Pour améliorer l'expérience de développement avec Python, il est recommandé d'installer quelques extensions :

### Extension Python
1. Ouvrir VS Code.
2. Cliquer sur l'icône "Extensions" dans la barre latérale gauche (ou appuyer sur `Ctrl+Shift+X` ou `Cmd+Shift+X` sur Mac).
3. Rechercher "Python" par Microsoft.
4. Cliquer sur "Install". Cette extension fournit un support riche pour Python, incluant l'autocomplétion, le débogage, et l'intégration avec des environnements virtuels.

### Jupyter Notebooks dans VS Code
VS Code a un support intégré pour les notebooks Jupyter. Après avoir installé l'extension Python, vous pouvez ouvrir et exécuter des fichiers `.ipynb` directement dans VS Code.

1. Créer un nouveau fichier avec l'extension `.ipynb` (par exemple, `mon_notebook.ipynb`).
2. VS Code reconnaîtra automatiquement le fichier comme un notebook Jupyter.
3. Vous pouvez ajouter des cellules de code et de texte, et les exécuter.

### Google Colaboratory (Colab)
Pour ceux qui préfèrent utiliser des notebooks en ligne sans installation locale, Google Colab est une excellente alternative.

1. Aller sur [Google Colab](https://colab.research.google.com/).
2. Connectez-vous avec votre compte Google.
3. Vous pouvez créer un nouveau notebook, ouvrir un notebook depuis Google Drive, GitHub, ou uploader un fichier `.ipynb` depuis votre ordinateur.
4. Colab fournit un environnement Python hébergé avec accès gratuit à des GPU/TPU, idéal pour les tâches de calcul intensives.
5. Pour collaborer, vous pouvez partager votre notebook Colab de la même manière que vous partageriez un document Google Docs.
