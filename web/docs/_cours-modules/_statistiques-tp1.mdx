:::info Analyse de données scientifiques
        L'un des usages les plus fréquents des listes et des boucles en sciences est de calculer des métriques statistiques sur un ensemble de mesures.
        :::

        ---\

        :::note Calcul du maximum, du minimum et de la moyenne
        ```python showLineNumbers
        donnees = [45.2, 88.0, 92.5, 60.1, 78.4]

        # 1. Calcul du maximum
        max_val = donnees[0]
        for val in donnees:
            if val > max_val:
                max_val = val

        # 2. Calcul de la moyenne
        somme = 0
        for val in donnees:
            somme += val
        moyenne = somme / len(donnees)

        print(f"Valeur maximale : {max_val}")
        print(f"Moyenne : {moyenne:.2f}")
        ```
        :::
