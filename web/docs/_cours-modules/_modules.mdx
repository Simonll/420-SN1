        ::::info Les modules en Python

        Python contient de nombreuses fonctions prêtes à l’emploi pour effectuer des calculs, manipuler des fichiers, gérer du texte, produire des nombres aléatoires, etc.\
        Cependant, elles ne sont pas toutes chargées automatiquement au démarrage.
        **Pourquoi?** Pour garder Python plus léger et éviter de charger inutilement des outils dont on n’a pas besoin.

        Ces fonctions sont regroupées dans des fichiers Python (`.py`) appelés **modules**.\
        Un **module**, c’est donc un fichier qui contient des fonctions organisées autour d’un thème.

        Pour utiliser les fonctions d’un module, il existe deux approches principales :

        <Row>
            <Column size={6}>

                :::note MÉTHODE #1

                Importer le module complet

                ```python showLineNumbers
                # Importer le module "math"
                import math

                print(math.sqrt(16)) # Résultat : 4.0
                print(math.cos(5))   # Résultat : 0.28366218546322625
                ```

                C’est la méthode la plus courante.\
                On accède aux fonctions du module avec la syntaxe :
                ```python
                nom_du_module.nom_de_la_fonction()
                ```

                Par exemple :
                ```python
                math.sqrt(16)
                ```

                :::

            </Column>

            <Column size={6}>

                :::note MÉTHODE #2

                Importer une fonction spécifique

                ```python showLineNumbers
                # Importer juste les fonctions "sqrt" et "cos"
                from math import sqrt, cos

                print(sqrt(16)) # Résultat : 4.0
                print(cos(5))   # Résultat : 0.28366218546322625
                ```

                Cette méthode est utile lorsqu’on utilise seulement quelques fonctions précises d’un module.

                L’avantage est qu’on n’a pas besoin de répéter le nom du module devant chaque fonction.

                :::

            </Column>
        </Row>

        En général, on écrit les `import` et les `from` au **début du fichier Python**.\
        **Pourquoi?** Quand quelqu’un ouvre le fichier, il peut voir immédiatement quels modules le programme utilise.

        :::tip Les alias

        On peut donner un **surnom** à un module ou à une fonction avec le mot-clé `as`.\
        C’est très courant en Python, surtout pour les modules dont le nom est long.

        <Row>
            <Column size={6}>
                ```python showLineNumbers
                # Donner un alias à un module
                import random as rd

                print(rd.randint(1, 10))
                ```
            </Column>
            <Column size={6}>
                ```python showLineNumbers
                # Donner un alias à une fonction spécifique
                from time import sleep as pause

                pause(2)  # Le programme s'arrête pendant 2 secondes
                ```
            </Column>
        </Row>

        :::

        :::info Modules utiles en Python
        Vous trouverez la documentation officielle des modules de base sur le site officiel de Python. \

        - `time` → manipulation du temps et des dates (mesurer le temps écoulé, conversions de format) - ([doc](https://docs.python.org/fr/3.13/library/time.html))
        - `csv` → lecture/écriture de fichiers CSV (format courant pour stocker des données tabulaires) - ([doc](https://docs.python.org/fr/3.13/library/csv.html))

        :::info Bibliothèques

        Parfois, plusieurs modules sont regroupés ensemble pour former un tout réutilisable et
        partageable facilement.<br />
        Nous appelons ce regroupement une **bibliothèque**.

        **Points clés :**
        - Chaque module d’une bibliothèque peut contenir des fonctions, classes ou constantes spécifiques.
        - Pour utiliser une bibliothèque externe, il faut d'abord l'installer dans l'environnement virtuel de votre projet. Cela se fait généralement avec la commande `pip install nom_de_la_bibliothèque` dans le terminal.
        - Une fois installée, on peut **importer ses modules** comme pour un module Python classique.

        ```python showLineNumbers
        import numpy # Importer la bibliothèque "numpy"
        print(numpy.array([1, 2, 3]))
        ```

        Voici quelques bibliothèques populaires en Python :
        - `numpy` → calculs numériques avancés, manipulation de tableaux multidimensionnels - ([documentation officielle](https://numpy.org/doc/stable/))
        - `pandas` → manipulation et analyse de données tabulaires (*DataFrames*) - ([doc](https://pandas.pydata.org/docs/))
        - `matplotlib` → création de graphiques et visualisation de données - ([doc](https://matplotlib.org/stable/index.html))
        - `scikit-learn` → apprentissage automatique (*machine learning*), modèles prédictifs - ([doc](https://scikit-learn.org/stable/user_guide.html))
        - `keras` → création et entraînement de réseaux de neurones pour l'apprentissage profond (*deep learning*) - ([doc](https://keras.io/guides/))

        :::

        ---

        :::tip Alias de bibliothèque
        On peut donner un alias à une bibliothèque lors de son importation pour simplifier son utilisation.<br />
        Par exemple, on peut importer la bibliothèque `numpy` avec l'alias `np` pour faciliter son utilisation dans le code et éviter d'écrire `numpy` au long.<br />

        Il suffit d'utiliser le mot-clé `as` lors de l'importation :
        ```python showLineNumbers
        import numpy as np          # Importer la bibliothèque "numpy" avec l'alias "np"
        print(np.array([1, 2, 3]))  # Utiliser l'alias "np" (au lieu d'écrire numpy) pour accéder à la fonction "array()"
        ```
        :::
