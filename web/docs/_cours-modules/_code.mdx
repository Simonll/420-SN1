::::note Écrire et exécuter ses premières commandes Python

Google Colab utilise des **cellules de code** interactives. C'est comme un cahier de notes où chaque bloc de code peut être exécuté indépendamment.

**1. Ouvrez le notebook d'introduction dans Colab :**

<a href="https://colab.research.google.com/github/Simonll/420-SN1/blob/develop/code/notebooks/01-rencontre1.ipynb" target="_blank"><img src="https://colab.research.google.com/assets/colab-badge.svg" alt="Open In Colab"/></a>

> Si vous n'avez pas de notebook pour cet exercice, vous pouvez simplement ouvrir Google Colab et créer un nouveau notebook (`Fichier > Nouveau notebook`) et copier-coller le code ci-dessous dans la première cellule.

**2. Exécutez votre première cellule de code :**

Dans le notebook, vous verrez une cellule de code. Cliquez sur l'icône de lecture (▶️) à gauche de la cellule ou sélectionnez la cellule et appuyez sur `Maj + Entrée` pour l'exécuter.

```python
print("Bonjour le monde!")
```

Le résultat s'affichera juste en dessous de la cellule :
```
Bonjour le monde!
```

Décortiquons cette première ligne de code :

- **`print`** : C'est une fonction native de Python. En programmation, « imprimer » signifie afficher un résultat textuel.
- **`()`** : Les parenthèses contiennent ce que la fonction doit utiliser (l'argument).
- **`""`** : Les guillemets indiquent que `"Bonjour le monde!"` est du texte brut (une chaîne de caractères) et non une commande.

**3. Utilisez Colab comme une super calculatrice :**

Tapez une expression mathématique dans une nouvelle cellule et exécutez-la. Python l'évaluera et affichera le résultat.

```python
6 / 2 * (1 + 2)
```

Résultat :
```
9.0
```

Cette capacité à saisir une instruction et à obtenir une réponse immédiate s'appelle le mode interactif. C'est un bac à sable exceptionnel, idéal pour tester des formules, explorer des idées ou valider un comportement logique rapidement.

:::tip
Dans Colab, vous pouvez utiliser les touches Flèche haut ($\uparrow$) et Flèche bas ($\downarrow$) dans une cellule pour naviguer dans l'historique des commandes que vous avez tapées dans cette cellule.
:::
