:::danger Tolérance zéro pour le plagiat
Si un travail remis est suspecté de plagiat (code copié sur un ou une collègue, généré par une IA, ou utilisant des notions non vues en classe), voici ce qui se produira :

- **Preuve formelle :** Si nos outils détectent un plagiat de façon catégorique, c'est la note de 0 automatiquement.
- **Validation requise :** Si le doute est fort mais nécessite une vérification, vous serez convoqué(e) au bureau de votre enseignant(e). Vous devrez expliquer et démontrer que vous maîtrisez parfaitement le code remis. L'incapacité à expliquer le fonctionnement de votre propre code entraînera la note de 0 (ne pas comprendre ce qu'on a remis équivaut à avoir triché).
:::

:::tip Entraide vs Plagiat : Comment tracer la ligne ?
En programmation, la limite entre « s'entraider » et « copier » peut parfois sembler floue. Voici nos règles d'or pour collaborer sainement :

- **Ne partagez jamais vos fichiers ou blocs de code.** Même avec de bonnes intentions, la personne aidée finira souvent par copier-coller sans réfléchir.
- **Expliquez la logique, pas la syntaxe.** Vous avez tout à fait le droit de faire des dessins, d'expliquer un algorithme ou de reformuler un problème, mais vous ne devez jamais écrire (ou dicter) le code à la place de quelqu'un d'autre.
- **En cas de doute, levez la main !** Votre enseignant(e) est la meilleure personne pour vous décoincer.
:::
