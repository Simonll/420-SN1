:::info Fonctions

Une **fonction** est un ensemble d'instructions réutilisables regroupées sous un nom.<br />
Le nom doit être **significatif** : par exemple, on devine que `print()` sert à afficher quelque chose.

---

### Comprendre une fonction
Quand on utilise une fonction, il n'est pas nécessaire de connaître tout son code interne.<br />
Il faut surtout comprendre :
- Quels **paramètres** attend-elle ? (les infos entre `()`)
- Est-ce qu'elle **retourne une valeur** qu'on peut stocker ?
- Y a-t-il des **cas limites** ou erreurs possibles (exceptions) ?

---

### Les paramètres
Pour appeler une fonction :
`nom_de_fonction(param1, param2, ...)`<br />
Le nombre et l'ordre des paramètres sont importants.

---

### Conserver une valeur de retour
On peut stocker le résultat d'une fonction dans une variable, par exemple :
```python showLineNumbers
mon_age_arrondi = round(17.8)
```
:::

:::warning La distinction `print()` vs `return`
La distinction entre `print()` (afficher) et `return` (renvoyer une valeur) est cruciale. Consultez cette [page](/aidememoire/return-print) de l'aide-mémoire pour une explication détaillée.
:::

### Les fonctions `min()` et `max()`
Les fonctions `min()` et `max()` permettent de connaître le paramètre ayant la plus petite ou la plus grande valeur.<br />
Ces deux fonctions doivent être utilisées avec des paramètres.<br />

Par exemple :
```python showLineNumbers
# Trouver le plus petit
note1 = 85
note2 = 72
note3 = 91
plus_petite = min(note1, note2, note3)
print(f"La plus petite note est : {plus_petite}")  # 72

# Trouver le plus grand
plus_grande = max(note1, note2, note3)
print(f"La plus grande note est : {plus_grande}")  # 91
```

À noter : les fonctions `min()` et `max()` sont particulières en ce sens qu'elles peuvent prendre un nombre variable de paramètres, contrairement à la plupart des fonctions qui attendent un nombre fixe de paramètres.

### La fonction `len()`
La fonction `len()` permet de calculer la longueur d'une séquence, comme une **chaîne de caractères** (nombre de caractères) ou une **liste** (nombre d'éléments).<br />
Elle prend la séquence en paramètre et retourne un entier.

```python showLineNumbers
# Avec une chaîne de caractères
prenom = "Alice"
longueur_prenom = len(prenom)
print(f"La longueur du prénom {prenom} est : {longueur_prenom}")  # La longueur du prénom Alice est : 5

# Avec une liste
notes = [85, 92, 78]
nombre_de_notes = len(notes)
print(f"Il y a {nombre_de_notes} notes.") # Il y a 3 notes.
```
Le concept de liste sera abordé plus en détail dans l'onglet **Liste (list)**.

### Appels imbriqués

On peut imbriquer les appels de fonctions pour combiner plusieurs opérations en une seule ligne.<br />
Ainsi, la valeur retournée par une fonction peut être utilisée directement comme paramètre d'une autre fonction.<br />
```python showLineNumbers
print(len(str(42)))
```
Dans cet exemple, où trois appels de fonctions sont imbriqués, l'exécution se fait de l'intérieur vers l'extérieur :
1. La fonction `str(42)` convertit le nombre entier `42` en une chaîne de caractères `"42"`,
2. puis la fonction `len(...)` calcule la longueur de cette chaîne, qui est `2`,
3. et enfin la fonction `print(...)` affiche ce résultat.

---

### La fonction `print()`

`print()` est la fonction la plus utilisée pour afficher du texte ou des valeurs dans la console. \
Elle peut prendre un nombre variable de paramètres, séparés par des virgules, qu'elle *concaténe* avec des espaces par défaut.

```python showLineNumbers
nombre1 = 6
nombre2 = 7
print("Le résultat de", nombre1, "x", nombre2, "est :", nombre1 * nombre2)
```

Par défaut, chaque `print()` termine par un saut de ligne :

```python showLineNumbers
print("1")
print("2")
print("3")
```
```
1
2
3
```

Il est possible de remplacer ce saut de ligne avec le paramètre nommé `end` :

```python showLineNumbers
print("1", end=" ")
print("2", end=" ")
print("3", end=" ")
```
```
1 2 3
```

Le concept de paramètre nommé (comme `end=`) sera étudié dans la prochaine rencontre.
